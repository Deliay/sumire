# 视觉识别系统（Visual Identity）

本文档定义枝堇Sumire 粉丝站的视觉语言，所有页面与后续工具都必须遵守。设计的一切依据来自人设本身：**老书屋的藤蔓少女**。

## 1. 设计概念

**关键词**：雨夜书屋 · 藤蔓 · 旧纸张 · 蕾丝 · 雾 · 微光紫花

一句话：*深夜的老书屋里，纸页泛黄，雾气从窗缝渗进来，藤蔓在书架间缓慢生长，堇色的花发着微光。*

- **深色为底**：站点整体是"夜晚的书屋"，深色背景承载氛围；
- **纸页为器**：需要阅读的内容（设定故事、文案）放在浅色"纸页"卡片上，形成明暗对比，呼应"破旧纸张"；
- **藤蔓为线**：分隔线、时间轴、装饰角一律使用藤蔓曲线，禁止生硬的直线分割；
- **蕾丝为框**：卡片与头图的边框装饰取自人设的蕾丝元素；
- **紫花为光**：高亮与强调色取自人设头发上发光的堇色花，面积克制。

## 2. 色彩系统

### 2.1 色彩 Token

> **调色盘口径（首页视觉效果优化 v1）**：需求「重新按应援主题色 `#b4a6bf` 设计调色盘」经评估后，确认现调色盘**本身已是 `#b4a6bf` 衍生体系**（`primary #b4a6bf` 为官方应援色，`primary-deep/soft/paper/ink/flower/vine/eye` 均为其明度/饱和度/色相派生），**本期维持现调色板不变**，仅新增 `--text-*` 字阶 token 并整体上调字号（见 §3.1）。不再做衍生色色值重写，以控制全站（含 `/backdoor`）回归面。

| Token | 色值 | 用途 | 来源 |
|-------|------|------|------|

| `--color-paper` | `#f0eaf4` | "纸页"卡片底色（浅色阅读面） | 旧纸张+蕾丝白 |
| `--color-paper-dim` | `#d9cfe0` | 纸页上的次级元素 | 纸页派生 |
| `--color-ink` | `#efeaf4` | 深底上的主文字 | |

| `--color-eye` | `#7fb0e6` | 极少量点缀（如直播状态点） | 蓝瞳 |

### 2.2 使用规则

- 深色底为主，纸页卡片仅用于长文阅读与需要突出的内容块；
- `--color-flower` 单屏出现面积不超过 ~5%，只做"点睛"，禁止大面铺色；
- 文本对比度满足 WCAG AA（正文 ≥ 4.5:1）；
- 应援色 `#b4a6bf` 不做正文文字色（对比度不足），用于图形与强调元素。

## 4. 质感与图形元素

| 元素 | 实现方式 | 使用位置 |
|------|---------|---------|
| 藤蔓分隔线 `VineDivider` | SVG 曲线 + 小花节点，可带缓慢"生长"动画 | 区块之间、时间轴轴体 |
| 蕾丝边框 `LaceFrame` | 边框贴图/重复纹样（取自宣传图蕾丝横幅重绘） | 主页 hero 顶部、素材卡片 hover、页脚顶部 |
| 纸页纹理 | 细微噪点 + 轻微泛黄的径向渐变 | 纸页卡片底色 |
| 雾气 | 大面积径向渐变 + 缓慢漂移（transform） | 主页 hero、页头背景 |
| 藤蔓角饰 | SVG 角花（参考周表图四角） | 纸页卡片四角、素材卡片 |
| 紫花微光 | 径向渐变光晕 + 花瓣图形 | 强调节点、时间线节点、加载态 |

## 5. 动效规范

- **气质**：缓慢、呼吸感。藤蔓生长、雾气漂移，禁止弹跳、快速滑入等"活泼"动效；
- 时长基准：入场 400–600ms（ease-out），环境动效（雾、藤蔓）≥ 8s 循环；
- 藤蔓生长用 SVG `stroke-dashoffset` 过渡；
- **reduced-motion 口径（展示向）**：公开站氛围层（首页雾气、藤蔓生长、视差、粒子、翻页转场与冲量）对 `prefers-reduced-motion: reduce` **不降级**——展示向站点以氛围动效为核心卖点，reduced 用户体验与常规一致；后台 `/backdoor` 仍尊重该偏好，关闭环境动效、入场改为直接呈现。
- 装饰动画只用 `transform` / `opacity`，避免布局抖动。

## 6. 图标与插画

- 图标：细线风格（1.5px 描边、圆角端点），可用 Lucide 并统一线宽；
- 装饰插画一律取自官方素材（`references/`）或据此重绘的藤蔓/花/蕾丝元素，不使用第三方插画；
- 头像/立绘使用透明底 PNG，置于雾色径向渐变之上。
