壹 CONCEPT / 设计概念

装订：一本书的五件事

装饰不表达结构，就会被当成贴纸。这一版只用五个「书」的元素承担全部视觉识别， 其余一律留给字号、留白与 1px 线。

图版立绘 / 插画放进无圆角 1px 描边框，下方带题注

唯一的高风险动作 桌面竖排书名 + 贯穿全站的装订线。不接受可退回横排，其余方案不受影响。

贰 COLOR / 色彩

深墨底，暖骨白，堇色只点一处

不再让 primary / flower / vine / eye 四色同时抢注意力。堇色是唯一品牌强调色， 功能语义色（eye / crimson / gold）只在弹幕看板、直播状态等有语义的位置出现。

使用规则

  • vine token 废弃，全部替换为 line / line-strong。
  • flower 不再承担大面积背景与光晕，只做焦点、链接、状态点。
  • 应援色不做小号正文色（对比度不足），只用于图形、页码、活动态与大号文字。
  • 单屏应援色面积 ≤ 5%。

同一行字的三种层级

主文字：档案、正文、标题。

次级文字：说明、元数据、题注。

禁用文字：不可点击、不可读的提示。

层级只靠明度与字号，不靠发光，也不靠颜色反白。

叁 TYPE / 字体与字阶

宋体读书，黑体做事，等宽记事

花体斜体从前被当成章节标签到处使用，承担了信息职责。现在它只出现在字标、图版编号与卷次； 章节标签交给等宽大写字距——好看是其次，认得出来才是第一。

肆 LAYOUT / 版心与结构线

先对齐，再谈风格

现在导航全屏宽、/about 限宽 4xl、/assets 全幅、页脚限宽 6xl——左右边线对不齐， 这是「不好看」最直接的结构性来源。全站只留两条版心。

伍 COMPONENTS / 组件

按钮、输入、标签、面板与图版

这一节全部是可交互样品：鼠标移上去就是真实 hover 态，Tab 进去就是真实焦点环。 评审时请直接操作，而不是只看截图。

Button 四变体 / 两尺寸 / loading / disabled

主按钮一屏只有一个。没有泛光、没有渐变、没有上浮；hover 只换底色。

Field default / focus / error / disabled

标签在上、等宽大写；错误态用 crimson 描边 + 下方文案，不靠颜色单独表意。

柒 MOTION & A11Y / 动效与可访问性

只留三种动效

入场、悬停、翻页。环境循环动效全部删除；prefers-reduced-motion 不再有「公开站特批」， 全站一视同仁。

动效规格
入场opacity 0→1 + translateY 8px→0，480ms，cubic-bezier(.22, 1, .36, 1)
悬停 / 焦点只改颜色、描边、透明度，140ms
整页翻页当前屏淡出 + 上移 8px，下一屏反向，480ms；装订线与页码不参与位移
弹层遮罩淡入，内容上移 8px，220ms
reduced-motion无位移 / 缩放 / 视差 / 粒子；翻页 120ms 纯淡入或即时
循环动效仅直播状态点 pulse（本页左上角那一个）

可访问性基线

  • 正文与次级文字对比度 ≥ 4.5:1；大号文字 ≥ 3:1（色板已列实测值）。
  • 所有交互元素 :focus-visible 2px flower 焦点环 + 2px 外偏移，不被 overflow-hidden 裁剪。
  • 触摸目标 ≥ 44×44；键盘可完成导航、菜单、筛选、下载、关闭弹层。
  • 移动抽屉与弹层：焦点陷阱、Esc 关闭、关闭后焦点回到触发元素、锁定背景滚动。
  • 提供「跳到正文」skip link（本页 Tab 第一下即可见）。
  • 不出现仅靠 hover 才能获取的信息；不靠颜色单独区分状态。
捌 DECISIONS / 请重点确认

六件事，你点头我才往下做

以下每条都写清了「建议」和「代价」。有异议直接在这里圈出来，不必等实现完再返工。

01 移除粒子 / 视差 / 雾气 建议移除，改为静态径向微光 + 暖骨白排版。站点从「动效氛围」转为「编辑设计」。 代价：少了动效卖点；收益：去掉视觉噪音、持续重绘与耗电，移动端不晕动。 已按「移除」绘制
02 reduced-motion 全站尊重 建议把「公开站氛围层不降级」的特批改为全站尊重。代价：需同步修改设计文档与 spec 中的旧口径； 收益：可访问性一致，代码不再分叉。 本页已遵循
03 档案五屏取消左右交替 建议取消交替，文字恒左、图版恒右。代价：少了「翻页节奏」的视觉变化； 收益：阅读位置稳定，五屏一套规则，移动端可直接单列堆叠。 已按「固定轴」绘制
04 后台只做 token + 控件 + 壳层 建议不重排后台业务页布局。代价：后台与公开站气质不完全一致； 收益：回归面可控，不会在改视觉的同时碰坏管理流程。 范围已收窄
05 保留整页翻页 deck 建议保留，只重做视觉与索引。若改成普通长页，属信息架构变更，不在本期范围。 本期不改 IA
06 桌面竖排书名 建议采用，移动端横排，@supports 回退。这是整站唯一「一眼记得住」的排版动作。 若风险太高可退回横排，其余设计不受影响。 ← 封面即样品
确认方式 在 PR 中逐条回复「同意 / 改 X」，或直接在对应小节圈注。概念页只定方向，实现细节以 PRD 与实现方案为准。
