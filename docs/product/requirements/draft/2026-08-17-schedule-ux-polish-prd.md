# 直播计划体验优化

**功能名称**: 直播计划体验优化（Schedule UX Polish）
**PRD 版本**: v1.0
**创建日期**: 2026-08-17
**作者**: sumire workflow

## 一、背景与目标

### 1.1 背景

直播计划功能（公开页 `/calendar` 日历 + 后台 `/backdoor/schedule` 计划管理与周表图生成）已上线，现态以 `docs/product/spec/calendar.md` 与 `docs/product/spec/schedule-admin.md` 为准。投入使用后收集到四点体验问题：

1. 后台新增/编辑直播计划时，「日期」「时间」输入框未声明 `autocomplete`，浏览器每次聚焦都弹出自动填充联想，遮挡定制浮层，输入体验差；
2. 后台「生成周表图」功能在部分浏览器上字体绘制缺少抗锯齿，导出图片文字发虚/锯齿明显（当前画布 1× 渲染，无超采样与平滑设置）；
3. 后台直播计划页的日历格子（cell）高度由内容撑开、行间不齐，且日历容器不随页面剩余空间伸展，页面下方留白或出现双滚动条；
4. 各页面加载骨架使用默认 `animate-pulse`（2s 周期），呼吸闪烁过快，观感焦躁。

### 1.2 目标

- 计划表单「日期」「时间」输入框不再触发浏览器自动填充联想；
- 周表图文字在所有现代浏览器上平滑无锯齿（导出尺寸不变，1665×1080 PNG）；
- 后台直播计划页日历各行格子等高均分，日历容器顶满页面剩余高度；
- 全站骨架/加载动画降速，无急促闪烁感，且尊重 `prefers-reduced-motion`。

### 1.3 成功标准

- [ ] 聚焦「日期」「时间」输入框时不再弹出浏览器自动填充下拉（定制浮层行为不变）；
- [ ] 周表图导出 PNG 尺寸仍为 1665×1080，文字边缘平滑（Chrome/Firefox/Safari 最近两个大版本目检无锯齿）；
- [ ] 后台日历月视图各行格子等高，日历整体撑满视口剩余高度，无内容多少导致的高度跳变；
- [ ] 骨架动画周期放缓（≥3s），切换加载态时无急促闪烁；开启系统「减少动态效果」时动画仍被禁用。

## 二、用户分析

### 2.1 目标用户

- 后台管理员（admin / superadmin）：录入与调整直播计划、生成周表图；
- member 角色：只读浏览后台计划页；
- 公开页访客：浏览 `/calendar` 与首页「本周日程」（间接受益于骨架降速）。

### 2.2 用户场景

| 场景 | 用户角色 | 目标 | 痛点（现状） |
|------|----------|------|------|
| 录入直播计划 | admin | 快速填写日期/时间 | 浏览器自动填充弹层反复遮挡日期/时间选择浮层 |
| 生成周表图 | admin | 导出清晰周表图发布 | 部分浏览器导出图文字锯齿明显 |
| 浏览计划日历 | admin/member | 整页览阅月度计划 | 格子行高不齐、容器不顶满，版面松散 |
| 等待数据加载 | 全部 | 等待时视觉平静 | 骨架 2s 呼吸闪烁过快，观感焦躁 |

## 三、功能需求

### 3.1 功能概述

本期为直播计划相关界面的体验打磨，四点均为前端改造，无 API/契约/数据模型变更。

### 3.2 功能列表

#### F1 计划表单输入框关闭浏览器自动填充

**描述**: 新增/编辑直播计划弹层中的「日期」「时间」输入框（`DatePicker`/`TimePicker`）显式声明 `autoComplete="off"`，抑制浏览器自动填充联想。输入框既有的「未打开浮层时只读、聚焦打开定制浮层」交互不变。

**验收标准**:

- [ ] Chrome/Firefox/Safari 下聚焦「日期」「时间」输入框不弹出自动填充联想；
- [ ] 聚焦后定制月历浮层 / 时分滚轮浮层正常打开，手动键入行为不变；
- [ ] 表单其余字段（如标题）行为不受影响。

#### F2 周表图字体抗锯齿

**描述**: 周表图 Canvas 渲染改为显式抗锯齿：先以 2× 尺寸超采样绘制（底图与文字同比例放大），再开启高质量图像平滑缩放回 1665×1080 导出。导出格式、尺寸、配色、字体（Noto Serif SC）、布局坐标均不变。

**验收标准**:

- [ ] Chrome/Firefox/Safari 下导出 PNG 文字边缘平滑、无明显锯齿；
- [ ] 导出图尺寸仍为 1665×1080，底图与文字相对位置、字号视觉效果与现版一致；
- [ ] 同日多场拼接、缩放到下限截断加「…」等既有规则不变；
- [ ] 生成耗时无可感知劣化（本地生成 < 1s 量级）。

#### F3 后台日历格子等高且容器顶满

**描述**: 后台直播计划页（`/backdoor/schedule`）布局调整：页面主区域改为纵向 flex 容器并撑满视口剩余高度；日历月视图网格 6 行均分容器高度，每行格子等高（`1fr` 均分），格子内容超出时截断（沿用「每日最多 2 条」口径，不撑高行）。周视图行与当日弹层样式不变。

**验收标准**:

- [ ] 月视图 6 行格子严格等高，条目多少不影响行高；
- [ ] 日历容器顶满页面剩余高度（头部操作区之下、视口底部之上），无页面级纵向滚动条；
- [ ] 翻月、加载态与加载完成态之间无容器高度跳变（骨架与日历同占满剩余空间）；
- [ ] 窄屏（<640px）自动回退周视图的既有行为不变。

#### F4 骨架/加载动画降速

**描述**: 将骨架呼吸动画周期由默认 2s 放缓至约 3.2s（通过 Tailwind v4 `@theme` 自定义 `--animate-pulse` 时长实现，全站统一生效），降低闪烁感。动画仍遵循全局 `prefers-reduced-motion` 兜底（减少动态时禁用）。

**验收标准**:

- [ ] 后台计划页骨架、公开日历页骨架、首页「本周日程」骨架、弹幕看板骨架的呼吸周期 ≥3s；
- [ ] 开启系统「减少动态效果」后骨架为静态呈现；
- [ ] 非骨架的交互动效（过渡 ≤200ms）不受影响。

### 3.3 页面/界面描述

| 页面 | 描述 | 关键元素 |
|------|------|----------|
| `/backdoor/schedule` | 后台直播计划管理页（F1/F3/F4） | 计划表单弹层（日期/时间输入框）、月视图等高日历、顶满剩余高度的容器、降速骨架 |
| 周表图生成弹层 | 后台计划页「生成周表图」（F2） | 预览图与导出 PNG 文字平滑 |
| `/calendar`、首页 | 公开页（F4 间接受益） | 降速骨架 |

### 3.4 异常与边界情况

| 情况 | 预期行为 |
|------|----------|
| 浏览器忽略 `autocomplete="off"`（个别密码管理器扩展） | 属浏览器/扩展行为，不额外对抗；标准浏览器自动填充已抑制 |
| 底图加载失败/跨域 | 沿用既有错误提示口径，不因超采样改变 |
| 月视图某日条目超过「每日 2 条」上限 | 沿用既有截断展示，不撑高格子 |
| 极小视口高度（<400px） | 容器保持 `min-h` 兜底，允许页面滚动，不挤压格子到不可用 |
| 减少动态效果开启 | 骨架静态呈现，其余交互不变 |

## 四、非功能需求

### 4.1 性能

- 周表图 2× 超采样渲染为一次性本地计算，生成耗时不显著增加；
- 日历等高布局为纯 CSS（grid/flex），无每帧 JS 计算；
- 骨架动画为 CSS opacity 动画，不触发重排。

### 4.2 安全性

- 无新增接口与权限变更；`autoComplete="off"` 仅作用于非敏感字段（日期/时间），登录/改密表单的 autocomplete 口径不动。

### 4.3 兼容性

- 桌面现代浏览器（Chrome/Firefox/Safari 最近两个大版本）；视口断点口径不变（<640 / ≥640）。

## 五、依赖与约束

### 5.1 依赖

- 既有直播计划全部能力（契约 `contract/stream-plans.openapi.yaml`、周表图素材与坐标）不变。

### 5.2 约束

- 周表图导出尺寸 1665×1080 与布局坐标不变；素材坐标口径（`public/assets/original/AGENTS.md`）不变；
- 后台控件过渡 ≤200ms 与 Tailwind token 色规范（`docs/engineering/frontend-rules.md`）不变；
- 未上线的功能不得在 UI 中显示占位入口；
- 本期不动公开页日历的展示规则（每日条目数、合并规则）。

## 六、后续可能（本期不做）

- 周表图导出分辨率可配置（2×/3× 导出）；
- 骨架屏与内容布局完全同构（逐区块占位）；
- 计划表单浏览器原生 `type="date"`/`type="time"` 控件切换评估。
