# 弹幕看板视觉优化

**功能名称**: 弹幕看板视觉优化（Danmaku Board Visual Polish）
**PRD 版本**: v1.0
**创建日期**: 2026-08-19
**作者**: sumire workflow

## 一、背景与目标

### 1.1 背景

「弹幕看板」已历经一期（聚合展示 + 分栏 + 已读管理）与二期（更名、默认分栏、礼物图标、上船特写）及礼物金额筛选等迭代，现态以 `docs/product/spec/danmaku.md` 为准。运营在直播盯屏使用中提出四点视觉与交互优化：

1. 信息流目前完全没有视觉效果：新事件插入时列表生硬跳动（仅靠滚动锚定保证位置不跳），已有条目直接瞬移到新位置，盯屏时难以感知「有新事件进来了」以及它把哪些内容顶下去了；
2. 弹幕合并（重复弹幕折叠计数）当前恒开启，运营在需要对原始弹幕逐条核对（如确认具体发言人与时间点）时无法关闭；
3. SC（醒目留言）留言文字因条目整体 `select-none`（服务于双击已读交互）无法选中复制，运营需要摘取留言内容（如复制到答谢文案）时只能手打；
4. 弹幕条目对发送者身份（舰长/提督/总督）无视觉区分，高价值观众的弹幕淹没在普通弹幕中，需要一个极克制的身份提示。

### 1.2 目标

- 信息流增加克制的视觉动效：新事件插入时新条目有插入（入场）效果，既有条目以平移过渡让位，而非瞬移；
- 弹幕合并增加开关，默认关闭（关闭时弹幕逐条原样展示，不折叠计数）；
- SC 留言文字可以选中复制，且不与既有双击已读交互冲突；
- 弹幕条目按发送者船型（舰长/提督/总督）以对应 badge 颜色的 0.5% 透明度背景色打底，普通观众弹幕无背景。

### 1.3 成功标准

- [ ] 实时（SSE）新事件插入任一信息流时：新条目有可感知的插入效果，同列表既有条目平移让位，无瞬移跳变；历史分页 append 不触发入场动效；
- [ ] 动效克制（短时长、无弹跳/光效），遵循 `prefers-reduced-motion` 时降级为无动画；滚动锚定、「回到顶部」行为不变；
- [ ] 工具区提供「弹幕合并」开关，默认关闭；开启后行为与现况完全一致（折叠键、计数、末次锚定不变）；开关状态持久化，刷新后保持；
- [ ] SC 留言正文（含罗马音）可鼠标拖选复制；双击已读交互在留言文本之外区域保持可用，且复制操作不触发已读切换；
- [ ] 弹幕条目发送者为舰长/提督/总督时，条目以对应 badge 颜色（舰长蓝/提督紫/总督红）的 0.5% 透明度背景打底；普通观众与未知等级无背景；
- [ ] 既有能力零回归：分栏配置、混排/分节、礼物筛选、已读管理、虚拟化滚动、视口自适应。

## 二、用户分析

### 2.1 目标用户

- 后台管理员（admin / superadmin）：直播盯屏与答谢处理的主要使用者；
- member 角色：只读查看。

### 2.2 用户场景

| 场景 | 用户角色 | 目标 | 痛点（现况） |
|------|----------|------|------|
| 直播盯屏 | admin | 实时感知新事件流入与列表变化 | 新事件瞬移插入，视觉无反馈，容易看漏 |
| 弹幕核对 | admin | 需要时查看未折叠的原始弹幕流 | 合并恒开启，无法逐条核对重复弹幕的发送人 |
| 答谢文案准备 | admin | 复制 SC 留言内容引用/存档 | 留言文字 `select-none` 不可选中，只能手打 |
| 高价值观众识别 | admin | 弹幕流中识别舰长/提督/总督的发言 | 弹幕条目无身份视觉区分 |

## 三、功能需求

### 3.1 功能概述

本期为弹幕看板信息流的纯前端视觉与交互优化：插入/平移动效、弹幕合并开关（默认关闭）、SC 文字可复制、弹幕条目船型淡色背景。不涉及契约、服务端、接口变更；四项均作用于 `features/danmaku/` 展示层。

### 3.2 功能列表

#### F1 信息流视觉动效（插入与平移）

**描述**: 信息流（各栏各分节的虚拟化列表）增加克制的视觉动效：

- 实时（SSE）新事件插入列表顶部时，新条目以插入（入场）效果出现（如短时长淡入+下落），用户能明确感知新内容到来；
- 同列表既有条目在列表内容变化时以平移过渡移动到新位置，而非瞬移；
- 动效仅作用于实时插入；首屏历史加载与滚动分页 append（列表尾部追加）不播放入场动效；
- 遵循 `prefers-reduced-motion: reduce`：用户系统要求减弱动效时全部动效降级为无动画；
- 不影响滚动锚定（贴顶跟随/离顶锚定/「回到顶部」）与虚拟化行高测量。

**验收标准**:

- [ ] SSE 新事件到达时新条目有插入效果、既有条目平移让位，无瞬移跳变；
- [ ] 历史首屏加载与「加载更多」append 不触发入场动效；
- [ ] `prefers-reduced-motion` 下无任何动效；
- [ ] 滚动锚定、回到顶部、分页加载行为不变；列表滚动帧率不低于 30fps。

#### F2 弹幕合并开关（默认关闭）

**描述**: 弹幕合并（重复弹幕折叠计数，现况恒开启）增加开关：

- 开关置于弹幕看板顶层工具区（与「礼物筛选」同级），默认关闭；
- 关闭时弹幕逐条原样展示，不折叠、不显示「×N」计数；
- 开启时行为与现况完全一致：相同内容折叠为一条并累计计数（表情以表情图为键、文字以最长非重复子串为键、代表行锚定末次出现位置）；
- 开关为全局设置，对所有栏的弹幕分节同时生效；状态持久化在浏览器 localStorage，刷新后保持，配置损坏时回退默认（关闭）；
- 开关切换即时生效，不重新检索历史数据。

**验收标准**:

- [ ] 无本地配置的用户默认看到未合并的逐条弹幕流；
- [ ] 开启合并后折叠行为与现况一致（计数、锚定不移动）；
- [ ] 切换开关即时生效于所有弹幕分节，不触发重新检索；
- [ ] 开关状态刷新后保持；localStorage 值非法时回退关闭。

#### F3 SC 留言文字可复制

**描述**: SC 条目留言正文（含罗马音行）恢复可选中复制：

- 留言气泡内文字可鼠标拖选并复制；
- 与双击已读交互不冲突：在留言文本上的选择/复制操作不触发已读切换；条目其余区域的双击已读行为不变（admin 及以上）；
- member 只读口径不变（本就无已读交互）。

**验收标准**:

- [ ] SC 留言正文与罗马音可拖选复制；
- [ ] 在留言文本上拖选/双击不切换已读状态；
- [ ] 在留言文本之外的条目区域双击仍切换已读（admin），乐观更新/失败回滚行为不变。

#### F4 弹幕条目船型淡色背景

**描述**: 弹幕条目按发送者船型增加极克制的身份背景：

- 发送者为舰长/提督/总督（`sender.guardLevel` 3/2/1）时，弹幕条目以对应 badge 颜色（沿用船型强调色：舰长蓝 eye/提督紫 flower/总督红 crimson）的 **0.5% 透明度**作为条目背景色；
- 普通观众（无 `guardLevel`）与未知等级（非 1/2/3）无背景；
- 仅作用于弹幕（danmaku）条目；SC/礼物/上船条目不变（上船条目已有船型打底）；
- 背景为纯静态样式，无动画、无渐变、不影响行高与虚拟化测量。

> 说明：0.5% 透明度按需求原文执行（极浅、贴近底色的身份暗示）。若评审认为辨识度不足，可在技术提案评审中调整为 5% 等档位，调整不影响其余验收口径。

**验收标准**:

- [ ] 舰长/提督/总督发送的弹幕条目分别呈蓝/紫/红 0.5% 透明度背景，三档可辨且不喧宾夺主；
- [ ] 普通观众与未知等级弹幕无背景；
- [ ] 合并开启时折叠代表行按其代表事件的发送者等级渲染背景；
- [ ] 行高稳定，虚拟化滚动无抖动。

### 3.3 页面/界面描述

| 页面 | 描述 | 关键元素 |
|------|------|----------|
| `/backdoor/danmaku` | 弹幕看板主页面 | 工具区新增「弹幕合并」开关（默认关）；信息流插入/平移动效；SC 留言可选中；弹幕条目船型淡色背景 |

### 3.4 异常与边界情况

| 情况 | 预期行为 |
|------|----------|
| 合并开关 localStorage 值非法 | 回退默认（关闭） |
| 合并关闭时折叠导致的「列表未铺满自动填充」逻辑 | 不触发（无折叠）；维持既有短列表手动「加载更多」口径 |
| 发送者 `guardLevel` 缺失/为 0/非 1/2/3 | 弹幕条目无背景 |
| 合并开启时折叠代表行的背景 | 按代表事件（末次出现者）发送者等级渲染 |
| 系统开启 `prefers-reduced-motion` | 全部插入/平移动效降级为无动画，功能行为不变 |
| SSE 高密度事件连续插入 | 动效不叠加失真（新一批次直接取代进行中的动画），列表不失帧 |
| 窄屏单栏/全屏模式 | 四项功能同样生效 |

## 四、非功能需求

### 4.1 性能

- 动效仅使用 transform/opacity（合成层属性），不触发布局重排；滚动帧率不低于 30fps；
- 弹幕合并开关为纯前端渲染分支，切换不引入额外请求；
- 船型背景为静态类名，无每帧计算。

### 4.2 安全性

- 无接口与权限变更；沿用既有鉴权口径。

### 4.3 兼容性

- 同一二期：桌面现代浏览器最近两个大版本；视口断点不变（<640 / 640–1023 / ≥1024）；
- `prefers-reduced-motion` 媒体查询降级覆盖各主流浏览器。

### 4.4 可访问性

- 合并开关为带标签的开关控件（switch 语义），键盘可操作；
- SC 文本可选中本身即改善可访问性（屏幕阅读器/复制场景）。

## 五、依赖与约束

### 5.1 依赖

- 弹幕看板现有一二期与礼物筛选全部实现（`features/danmaku/`）；
- `@tanstack/react-virtual` 虚拟化（动效需与其定位/测量机制兼容）。

### 5.2 约束

- 纯前端改造，不改契约、不改服务端、无新增接口；
- Tailwind v4 `@theme` token 色（eye/flower/crimson），禁止硬编码色值；
- 未上线功能不得在 UI 中显示占位入口；
- 动效克制：短时长、无弹跳、无光效，遵循 `prefers-reduced-motion`。

## 六、后续可能（本期不做）

- 新事件提示音/桌面通知；
- 动效总开关（用户级禁用全部动效）；
- 弹幕条目船型背景透明度档位可调。
