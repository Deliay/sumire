# 首页视觉效果优化

**功能名称**: 首页视觉效果优化（Home Visual Overhaul）
**PRD 版本**: v1.0
**创建日期**: 2026-08-31
**作者**: sumire workflow

## 一、背景与目标

### 1.1 背景

现态首页（`apps/bookstore/app/(site)/page.tsx`，现态见 `docs/product/spec/site-pages.md`）为可纵向滚动的多区块页面：hero（左文案右立绘）、三张入口卡、本周日程大卡、信息速览条，页脚为多行排版。本次为**整体视觉效果优化**，目标是让首页成为一屏即完整的「封面页」：

1. 首页占满整个屏幕且**不可滚动**，信息密度收敛到一屏之内；
2. 立绘不再完整展示，改为右侧半屏宽、顶部起始 50% 高的氛围式裁剪展示；
3. 新增**直播状态**能力：API 代理内网上游「当前直播状态」接口对外提供 `GET /api/live/status`，首页展示直播状态组件，点击跳转枝堇直播间；
4. 首屏信息重构：移除与导航重复的入口卡、本周日程大卡与信息速览条，新增更轻量的「今日日程」组件；
5. 视觉焕新：按应援色 `#b4a6bf` 重新设计调色盘，整体字号稍大，风格简约大方；
6. 静态文案按「萌娘百科」词条校准更新。

### 1.2 目标

- 首页在任何视口下占满一屏且不可滚动，无溢出、无占位入口；
- 立绘①（持书）在桌面端占右侧 50% 宽、自顶部起展示 50% 高度；移动端宽度占满；
- 「VirtuaReal · 二十八期 / 枝堇 / Sumire / bio」文案块移至左下角并留出 padding，应援色复制按钮移除；
- 顶部导航保留并扩宽至全屏；
- API 新增公开接口 `GET /api/live/status`（代理内网上游 `state/current`），首页直播状态组件经该接口展示直播状态，点击跳转直播间；
- 首屏移除本周日程大卡、信息速览条、三张入口卡；新增「今日日程」组件；
- Footer 精简为一行，置于右下角：免责声明（移动端不展示）+「B 站空间 / 直播间 / 萌娘百科」三个链接；
- 调色盘按 `#b4a6bf` 重设、整体字号稍大，简约大方；
- `content/profile.yaml` 等静态文案与萌娘百科词条一致（仅官方公开信息，禁止二次设定）。

### 1.3 成功标准

- [ ] 桌面与移动端首页均 `100svh` 占满一屏、不可滚动，内容不溢出；
- [ ] 立绘桌面端右半宽 × 上半高（顶部起始）展示，移动端全宽展示；
- [ ] 文案块位于左下角且有 padding，页面中不再出现应援色复制按钮；

## 二、用户分析

### 2.1 目标用户

- **访客（粉丝/路人）**：打开首页即感知主播形象与「是否正在直播」，一键进入直播间；无需滚动即可看到今日安排；
- **后台管理员**：不受本需求影响（后台 `/backdoor` 不在本次范围）。

### 2.2 用户场景

| 场景 | 用户角色 | 目标 | 痛点（现状） |
|------|----------|------|--------------|
| 打开首页 | 访客 | 一屏内获得完整第一印象 | 需滚动才能看全，信息分散在多张卡片 |
| 看是否开播 | 访客 | 一眼确认直播状态并跳转直播间 | 首页无直播状态，只能凭入口卡盲跳 |
| 看今天播什么 | 访客 | 首屏看到当天计划 | 只有整周日程大卡，今天信息淹没其中 |

## 三、功能需求

### 3.1 功能概述

本次为前端首页布局/视觉重构 + API 新增一个公开读代理接口。前端仍为纯静态导出（SSG），直播状态与今日日程均在浏览器端经公开 API 获取，沿用 `API_CONFIGURED` 存在性守卫（未配置不渲染、不留占位）。契约先行：新增 `contract/live-status.openapi.yaml` 为单一事实源。

### 3.2 功能列表

#### F1 首屏全屏不可滚动布局

**描述**: 首页（`/`）改为占满整个屏幕（`100svh`）且**不可滚动**（桌面与移动端均不可滚动）。所有首屏元素（导航、立绘、文案块、直播状态组件、今日日程组件、footer 行）在该一屏空间内排布，任何视口下不产生纵向滚动条、内容不溢出。

**验收标准**:

- [ ] 桌面端（≥1024px）与移动端（<640px）首页均无纵向滚动；
- [ ] 常见视口（桌面 1280×800 及以上、移动 375×667 及以上）所有首屏元素完整可见、互不遮挡；
- [ ] 超矮视口等极端情况以核心元素（立绘、文案块、直播状态）优先，不出现布局破裂。

#### F2 立绘裁剪展示

**描述**: 「枝堇立绘 ①（持书）」（`standing-01`）由完整展示改为：自**顶部起始**、展示 `height: 50%`（视口高度的上半部分，图片以顶部为锚裁剪）；桌面端只占**右侧 50% 屏幕宽度**；**移动端宽度占满**（仍为顶部起始 50% 高度）。立绘作为首屏氛围元素，不遮挡文案与交互组件。

**验收标准**:

- [ ] 桌面端立绘位于右侧半屏，可见部分为图片自顶部起的内容，容器高度为视口 50%；
- [ ] 移动端立绘宽度占满屏幕，高度仍为视口 50%、顶部起始；
- [ ] 图片不变形（保持宽高比，裁剪而非拉伸）；
- [ ] 立绘不遮挡文案块、直播状态组件、今日日程组件与 footer 的可点击区域。

#### F3 文案块左下角重排

**描述**: 「VirtuaReal · 二十八期」「枝堇」「Sumire」「是老书屋的一株藤蔓，喜欢雨水和雾，破旧的纸张。」（bio，数据源 `content/profile.yaml`）整体移至**左下角**，四周留出 padding。**移除应援色复制按钮**（ColorChip），站点中不再出现该组件。

**验收标准**:

- [ ] 四段文案按现有层级（期数 → 枝堇/Sumire → bio）展示于左下角；
- [ ] 文案块与视口左/下边缘保持明确 padding（桌面大于移动端）；
- [ ] 首页及全站不再渲染应援色复制按钮。

#### F4 导航栏全屏宽

**描述**: 顶部导航（NavBar）保留现有链接与毛玻璃行为，内容区由限宽容器**扩宽至全屏**（与新的全屏首页匹配），左右仅留页面级 padding。

**验收标准**:

- [ ] 导航栏内容（品牌 + 链接）横向铺满全屏宽度，不再受 `max-w-6xl` 类限宽约束；
- [ ] 既有导航行为不变（滚动毛玻璃、移动端菜单、链接高亮）。

#### F5 直播状态 API

**描述**: `servers/api` 新增公开接口 **`GET /api/live/status`**：服务端代理内网上游 `http://vtuber.internal.fffdan.com/api/b/live/{roomId}/state/current`（`roomId` 固定为枝堇直播间 `1727076670`，与现有直播域口径一致，上游地址不出现在客户端可见位置），获取当前直播状态并归一化返回。

- 无需登录（公开读）；
- 短 TTL 缓存（直播状态时效性高，详见技术提案）；
- 上游超时/异常时**静默降级**：返回 `200 + { ok: false, ... }`，不产生 5xx（公开页口径，与 `/api/live-history` 一致）。

**验收标准**:

- [ ] 接口按契约 `contract/live-status.openapi.yaml` 实现，返回归一化的直播状态（含是否直播中等字段）；
- [ ] 未登录可访问；
- [ ] 缓存命中时不重复请求上游；
- [ ] 上游超时 / 非 2xx / 响应结构非法时返回 200 降级体，不产生 5xx；
- [ ] 上游地址与房间号不出现在客户端可见位置。

#### F6 直播状态组件

**描述**: 首页首屏新增**直播状态组件**（可基于被移除的应援色按钮样式改造），展示当前直播状态（如「直播中」「未开播」），**点击后跳转枝堇直播间**（`https://live.bilibili.com/1727076670`，新窗口）。数据来自 F5 接口，仅在 `API_CONFIGURED` 时挂载；请求失败/降级时展示为「未开播」以外的中性状态或按降级体展示（以契约为准），不出现错误堆栈。

**验收标准**:

- [ ] 组件在首屏可见（建议位置：左下文案块上方或邻近区域，具体以设计实现为准）；
- [ ] 直播中与未开播状态视觉可区分；
- [ ] 点击跳转直播间（`target="_blank"`，带 `rel="noopener"`）；
- [ ] `API_CONFIGURED=false` 时组件不渲染、不留占位；
- [ ] 初始渲染有固定尺寸占位（骨架），避免 hydration 布局跳动；
- [ ] 接口降级（`ok: false`）时组件展示中性状态，不报错、不破坏首屏布局。

#### F7 移除首屏冗余卡片

**描述**: 从首页移除以下区块：

1. **本周日程大卡**（`WeeklySchedule` 纸页大卡区块；日历页 `/calendar` 保留不受影响）；
2. **信息速览条**（生日/种族/所属/粉丝勋章四格 dl + 「了解更多 →」）；
3. **三张入口卡**（主播档案 / 周边素材 / 直播间，与导航栏重复）。

**验收标准**:

- [ ] 首页不再渲染上述三类卡片；
- [ ] `/calendar`、`/about`、`/assets` 等页面功能不受影响；
- [ ] 导航栏仍提供到达上述页面的入口（无死链）。

#### F8 今日日程组件

**描述**: 首屏新增**「今日日程」组件**：展示**当天**的直播计划（数据复用既有 `GET /api/stream-plans?from&to`，取当天日期），内容轻量（时间 + 主题）。当天无计划时展示空态文案（如「今日暂无安排」）。仅在 `API_CONFIGURED` 时挂载。

**验收标准**:

- [ ] 组件在首屏可见，展示当天计划的时间与主题；
- [ ] 当天无计划时展示空态文案；
- [ ] 请求失败时按既有静默口径处理（展示空态），不报错；
- [ ] `API_CONFIGURED=false` 时不渲染、不留占位；
- [ ] 初始渲染有固定尺寸占位，避免布局跳动。

#### F9 单行 Footer（右下角）

**描述**: Footer 精简排版为**一行**，在首页展示于**右下角**（贴边、留 padding）。内容依次为：

1. 免责声明：「本站为非官方粉丝作品，与 VirtuaReal 及主播本人无关；站内素材版权归枝堇Sumire 及 VirtuaReal 所有，请勿用于商业用途。」——**移动端不展示**；
2. 三个外链：「B 站空间」「直播间」「萌娘百科」（URL 单一事实源仍为 `content/site.yaml`，新窗口打开）。

Footer 为全站共享组件，本次将其统一精简为上述单行形态；在非首页页面沿用页面流式布局的底部呈现（不固定）。

**验收标准**:

- [ ] 首页 footer 单行展示于右下角，含免责声明 + 三个链接；
- [ ] 移动端首页 footer 仅展示三个链接（不展示免责声明）；
- [ ] 三个链接指向 `content/site.yaml` 的 bilibili / live / moegirl，新窗口打开；
- [ ] 非首页页面 footer 同为单行形态，布局不破裂；
- [ ] footer 不出现 `/backdoor` 链接（既有单测口径保持）。

#### F10 调色盘与字号

**描述**: 以应援主题色 `#b4a6bf` 为基准**重新设计全站调色盘**（在 `globals.css @theme` token 层面调整，衍生协调的背景/文字/点缀色阶），风格**简约大方**；**整体字号比现状稍大**（正文与标题字阶整体上调一档左右，以设计实现为准）。全站生效，不限于首页。

**验收标准**:

- [ ] 调色盘围绕 `#b4a6bf` 衍生，主色值不变；
- [ ] 全部样式仍仅使用 `@theme` token 色，无硬编码色值；
- [ ] 正文与标题字号整体可感知地大于现状；
- [ ] 文字与背景对比度满足 WCAG AA（正常文本 ≥ 4.5:1）；
- [ ] 后台 `/backdoor` 视觉不受破坏（共享 token 调整需回归后台页面）；
- [ ] `docs/design/01-visual-identity.md` 与 `02-page-design.md` 同 PR 同步。

- 其余字段（bio、喜好、不擅长的事、设定故事、历程、既有逸闻）与词条核对一致，不一致处以词条为准修正。

**验收标准**:

- [ ] 上述差异项落入 `content/profile.yaml`（及必要的 schema/页面展示扩展）；
- [ ] 与词条矛盾的既有文案被修正；
- [ ] `/about` 等引用页面正常展示新增内容；
- [ ] 内容仅含官方公开信息，无二次设定。

### 3.3 页面/界面描述

首页一屏布局建议（具体坐标/间距以设计实现为准，需同步 `docs/design/02-page-design.md`）：

| 区域 | 位置 | 内容 |

### 3.4 异常与边界情况

| 情况 | 预期行为 |
|------|----------|
| `NEXT_PUBLIC_API_BASE_URL` 未配置 | 直播状态组件与今日日程组件均不渲染，首页其余部分完整（沿用 `API_CONFIGURED` 守卫） |
| `/api/live/status` 上游超时/异常 | 接口返回 200 降级体；组件展示中性状态，首屏布局不破裂 |
| `/api/stream-plans` 请求失败 | 今日日程展示空态文案，不报错 |
| 当天无计划 | 今日日程展示「今日暂无安排」类空态文案 |
| 移动端竖屏空间不足 | 组件紧凑排布，核心元素（立绘/文案/直播状态）优先，不滚动不溢出 |
| 超宽/超矮视口 | 布局自适应，元素不重叠不遮挡 |
| `prefers-reduced-motion` | 沿用现态：氛围动效关闭 |
| 上游返回结构非法/缺字段 | 服务端防御式解析，按降级体处理，不 5xx |

## 四、非功能需求

### 4.1 性能

- 首页仍为纯静态导出（SSG），不引入服务端运行时取数；
- 直播状态/今日日程为 hydration 后客户端请求，不阻塞首屏渲染；带固定尺寸骨架避免 CLS；
- 直播状态接口服务端短 TTL 缓存，避免公开页流量直接打到内网上游。

### 4.2 安全性

- 上游地址与房间号仅存在于服务端配置，不出现在客户端可见位置；
- `roomId` 固定服务端内置，不暴露为客户端参数（防 SSRF）；
- 外链统一 `target="_blank"` + `rel="noopener"`；
- CORS 白名单口径不变。

### 4.3 兼容性

- 桌面现代浏览器（Chrome/Firefox/Safari 最近两个大版本）与移动端浏览器；
- 使用 `svh` 视口单位适配移动端动态工具栏。

### 5.1 依赖
