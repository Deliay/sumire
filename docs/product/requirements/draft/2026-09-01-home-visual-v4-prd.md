# 首页视觉效果优化 4 期

**功能名称**: 首页视觉效果优化 4 期（Home Visual FX v4：整页滚动叙事 · 档案五页 · 全幅日历 · 全幅素材）
**PRD 版本**: v1.0
**创建日期**: 2026-09-01
**作者**: sumire workflow

## 一、背景与目标

### 1.1 背景

首页视觉效果优化 1~3 期已上线：首页为 `100svh` 不可滚动封面页，含雾气、光晕粒子、立绘视差（鼠标 + 移动端传感器），详见 `docs/engineering/proposals/2026-08-31-home-visual-overhaul-proposal.md`、`2026-08-31-home-visual-v3-proposal.md`。

现态站点内容分散在三个独立路由：档案 `/about`、日历 `/calendar`、素材 `/assets`，首页仅是一张封面。作为「宣传官网」，访客需要点击导航在路由间跳转才能看到完整内容，首页积累的氛围（粒子、立绘、雾气）止步于首屏，缺乏一气呵成的叙事感。本期（4 期）把首页升级为**整页滚动叙事**的一体化体验：

1. **翻页式滚动**：首页依然占满整屏，但允许滚轮/触屏滚动——滚动后依然是占满整屏的模块，从「首页」→「档案」→「日历」→「素材」逐屏切换，模块间有转场动效；
2. **档案五页**：档案内容拆为 5 个整屏子页（信息/设定/喜好/历程/轶闻），立绘与内容左右分栏、单双页交替；
3. **日历与素材全幅化**：日历重排为占满屏宽的新样式（直角、中号字、左右全高翻月按钮、拖拽翻月）；素材区占满屏宽且作为最后一站可继续自然滚动到结尾；
4. **导航与位置指示**：顶部导航保留，点击平滑滚动到对应模块；新增竖向树状节点指示器，实时指示当前位于哪个模块的哪个子内容；
5. **粒子贯穿全场**：光晕粒子在所有模块可见，翻页时沿翻页方向加速、停止后速度滞留衰减（上浮/下坠感）。

### 1.2 目标

- 首页 `/` 重构为整页滚动容器：「首页 → 档案 P1~P5 → 日历 → 素材」共 8 个整屏站 + 素材尾部自然滚动区；一次滚轮手势/一次触屏滑动切换一个整屏（整页翻页，非自由滚动）；
- 顶部 NavBar 保持固定存在，导航项点击平滑滚动（翻页）到对应模块，当前模块在导航中体现选中态；
- 新增竖向树状节点指示器（SectionRail）：展示「模块 → 子内容」层级，指示当前位置，节点可点击跳转；
- 光晕粒子层常驻于整个滚动体验的所有模块；翻页时粒子获得与翻页方向一致的冲量加速，翻页停止后粒子速度按物理直觉滞留衰减（下翻下坠、上翻上浮），随后恢复常态漂移；
- 档案 5 页：立绘 + 内容左右布局，单数页立绘在左、双数页立绘在右；内容依次为 P1 信息・Profile / P2 设定・Story / P3 喜好・Taste / P4 历程・Journey / P5 轶闻・Trivia（复用现 `/about` 的五组内容）；
- 日历 section：直角 + 中号字、宽度占满屏幕、上月/下月为左右两侧高度占满的按钮、支持左右拖拽翻月（向左拖 = 下月，向右拖 = 上月）；
- 素材 section：宽度占满屏幕，其余口径不变；滚动到素材后释放为自然文档流，可一直向下滚动直到素材结尾，素材结尾后为站点 Footer；
- 整体滚动与交互有大气的转场效果，延续「紫花微光 / 雨夜书屋」视觉语言；
- 全部动效不产生布局偏移，不引入新运行时依赖；公开站氛围层对 reduced-motion 不降级（展示向口径），后台 `/backdoor` 仍严格执行 frontend-rules 的 reduced-motion 规范。

### 1.3 成功标准

- [ ] 首页 `/` 上一次滚轮手势（或一次触屏滑动）切换到下一/上一整屏，依次经过「首页 → 档案×5 → 日历 → 素材」，每屏占满视口；
- [ ] 滚动到素材区后可继续向下自然滚动浏览全部素材，直到素材结尾与 Footer；在素材自然滚动区向上滚回顶部后，继续上滚回到日历屏；
- [ ] 顶部导航始终可见；点击「档案 / 日历 / 素材」平滑翻页到对应模块（档案落到 P1）；当前所在模块在导航中有选中态；
- [ ] 竖向树状指示器展示完整层级（首页 / 档案及其 5 个子内容 / 日历 / 素材），当前位置节点高亮，点击节点可跳转；
- [ ] 粒子在所有模块背景可见；翻页瞬间粒子沿翻页方向明显加速，停止后速度滞留一小段再衰减恢复，下翻呈下坠感、上翻呈上浮感；
- [ ] 档案 5 屏按 P1~P5 顺序展示，单数屏立绘在左、双数屏立绘在右，移动端立绘在上内容在下；
- [ ] 日历直角 + 中号字、占满屏宽，左右侧全高按钮可翻月，左右拖拽可翻月（拖拽方向与翻月方向对应）；
- [ ] 素材区占满屏宽，分类筛选 / 网格 / Lightbox 口径不变；
- [ ] `prefers-reduced-motion: reduce` 时（含运行时切换）：公开站氛围层不降级——翻页转场（rAF 插值）、粒子冲量/滞留、视差满幅度、粒子全上限/明灭均与常规一致；
- [ ] 未配置 API 时日历模块从滚动序列、导航与指示器中移除（`API_CONFIGURED` 口径不变）；
- [ ] 独立路由 `/about`、`/assets`、`/calendar` 可正常直接访问，内容与首页对应模块一致；后台 `/backdoor/schedule` 日历样式不受影响；
- [ ] 键盘可用（方向键 / PageUp / PageDown 翻页、Tab 可达导航与指示器），无 CLS，无新增运行时依赖。

## 二、用户分析

### 2.1 目标用户

- 站点访客（桌面端为主、移动端次之）：从首页出发，一路滚动即可完整了解枝堇——她是谁（档案）、什么时候播（日历）、有哪些素材（素材）；
- 新访客：被首屏氛围吸引后，通过滚动叙事自然进入档案内容，无需理解站点导航结构；
- 移动端访客：以滑动手势获得与桌面端滚轮一致的逐屏浏览体验。

### 2.2 用户场景

| 场景 | 用户角色 | 目标 | 痛点（现状） |
|------|----------|------|--------------|
| 首访浏览全站 | 新访客 | 顺着首页一路看完档案、日历、素材 | 首页只是封面，需自行发现导航并跳路由，叙事断裂 |
| 反复查看日程 | 访客 | 快速从首页到达日历 | 需点击导航跳转 `/calendar`，粒子/氛围中断 |
| 浏览档案 | 访客 | 沉浸地逐节阅读设定 | `/about` 是一整页长文，缺乏节奏感与视觉变化 |
| 浏览素材 | 访客 | 翻阅全部素材 | 素材页宽度受限（72rem），大图排布局促 |
| 手机浏览 | 移动访客 | 滑动切换各模块 | 与桌面同样依赖导航跳转 |

## 三、功能需求

### 3.1 功能概述

本期为纯前端改动，全部位于公开站点（`apps/bookstore`），**不新增后端接口、不改动 API 契约、不改动后台**：

- F1：首页整页滚动容器（翻页式滚动序列 + 转场动效 + 素材区自然滚动收尾）；
- F2：竖向树状节点指示器（SectionRail）；
- F3：导航锚点化（点击滚动到模块 + 当前模块选中态）；
- F4：粒子滚动冲量（粒子常驻全体验 + 翻页加速 + 滞留衰减）；
- F5：档案五屏（P1~P5 左右交替布局）；
- F6：日历全幅新样式（直角中字、全高侧翻月按钮、拖拽翻月）；
- F7：素材全幅化（占满屏宽 + 尾部自然滚动）；
- F8：独立路由保留与内容复用（`/about` `/assets` `/calendar`）。

### 3.2 功能列表

#### F1 首页整页滚动容器

**描述**: 首页 `/` 由「100svh 不可滚动封面页」升级为**整页滚动容器**。滚动序列为 8 个整屏站：

| 序号 | 站 | 内容 |
|------|-----|------|
| 0 | 首页 | 现封面页内容（文案块 / 直播状态 / 今日日程 / 立绘，布局按新体验微调） |
| 1~5 | 档案 P1~P5 | 见 F5 |
| 6 | 日历 | 见 F6（未配置 API 时整站从序列移除） |
| 7 | 素材 | 见 F7，其后为素材自然滚动区与 Footer |

交互模型：**翻页式滚动**——一次滚轮手势（wheel 事件序列）/一次触屏滑动切换恰好一个整屏，手势过程中的快速连续滚动不连跳多屏（一次手势落定一屏）；支持键盘 `↓/↑`、`PageDown/PageUp` 翻页。模块间切换为占满整屏的转场动效（内容错峰滑入/淡出 + 立绘层位移，具体以实现定稿为准，须大气、克制、符合视觉语言）。滚到素材屏后，继续向下滚动**释放为自然文档流**（素材内容自由滚动直至结尾 + Footer）；在素材自然滚动区向上滚回素材屏顶部后，继续上滚则回到日历屏。首屏（首页站）保持 100svh 占满整屏。

**验收标准**:

- [ ] 一次滚轮手势/触屏滑动恰好切换一个整屏，不会一手势连跳多屏；
- [ ] 滚动序列顺序固定为 首页 → 档案 P1~P5 → 日历 → 素材；未配置 API 时日历站缺席、序列自动收敛；
- [ ] 每屏占满视口（100svh），切换过程平滑，结束后各屏内容稳定无回弹；
- [ ] 素材屏继续下滚进入自然滚动，可滚到素材结尾与 Footer；向上滚回素材屏顶部后继续上滚回到日历屏；
- [ ] 键盘 `↓/↑`、`PageDown/PageUp` 可翻页；`Home`/`End` 回到首屏/到达素材区；
- [ ] 移动端触屏滑动与桌面滚轮行为一致；
- [ ] 翻页过程仅使用合成层属性（`transform`/`opacity`），无 CLS；
- [ ] `prefers-reduced-motion: reduce` 时翻页转场仍为常规 rAF 插值（非淡切），翻页节奏与交互不变。

#### F2 竖向树状节点指示器（SectionRail）

**描述**: 在视口一侧（桌面端右侧边缘，移动端可弱化或收纳）新增固定的竖向树状节点图，呈现「模块 → 子内容」层级：

```
首页
档案
├─ 信息
├─ 设定
├─ 喜好
├─ 历程
└─ 轶闻
日历
素材
```

当前所在节点（精确到子内容，如「档案」的「信息」）高亮；已经过的节点与当前模块的父节点有弱化态区分。点击任一节点平滑翻页跳转到对应站。指示器视觉延续藤蔓/紫花语言（竖轴如藤蔓、节点如微光紫花，与历程时间轴呼应），`aria-hidden` 之外需提供等价的键盘可达跳转能力（指示器本身可作为导航 landmarks，或保证主导航可完成同等跳转）。

**验收标准**:

- [ ] 指示器完整展示层级，当前节点（模块 + 子内容）实时高亮；
- [ ] 翻页时高亮随滚动序列正确移动（档案内部 P1~P5 切换时高亮在 信息/设定/喜好/历程/轶闻 间移动）；
- [ ] 点击节点跳转到对应站，跳转过程与正常翻页转场一致；
- [ ] 未配置 API 时「日历」节点不出现；
- [ ] 素材自然滚动区内「素材」节点保持高亮；
- [ ] 键盘可完成等价跳转；公开站氛围层 `prefers-reduced-motion` 下不关闭生长/脉冲动效。

#### F3 导航锚点化

**描述**: 顶部 NavBar 保持固定存在、样式基调不变。导航项「主页 / 档案 / 素材 / 日历」改为锚点行为：

- 访客在首页 `/` 时：点击平滑翻页滚动到对应模块（「档案」落到 P1 信息）；
- 访客在其他路由时：点击跳转 `/#<section>`（浏览器定位后体验与首页一致）；
- 当前所在模块在导航中体现选中态（随滚动序列实时更新）；
- 「主页」点击回到首屏；B 站外链行为不变；移动端菜单内导航项同样生效。

**验收标准**:

- [ ] 首页内点击导航项平滑翻页到对应模块；
- [ ] 其他路由点击导航项跳转首页对应锚点；
- [ ] 当前模块选中态随滚动/翻页实时更新（档案 P1~P5 均视为「档案」选中）；
- [ ] 未配置 API 时导航不出现「日历」（口径不变）。

#### F4 粒子滚动冲量

**描述**: 光晕粒子层（`GlowParticles`）由首页背景提升为**整页滚动体验的常驻背景层**：覆盖所有模块（z 序保持在内容之下，层序不变），翻页/自然滚动全程可见。新增**滚动冲量**：翻页开始时，粒子获得与翻页方向一致的瞬时速度冲量（下翻向下、上翻向上），翻页结束、页面停止滑动后，粒子速度不立刻消失，而是按指数衰减滞留一小段时间（约 0.5~1.5s 量级，以实现定稿为准），形成「上浮/下坠后缓缓平复」的物理直觉效果；衰减结束后恢复常态缓慢漂移。冲量仅影响粒子运动，不改变粒子生成位置偏置（指针附近密度更高）等既有口径。粒子层全程 `pointer-events-none`、纯装饰。

**验收标准**:

- [ ] 粒子在所有模块（含素材自然滚动区）背景持续可见，不遮挡内容、不拦截交互；
- [ ] 向下翻页时粒子明显向下加速，停止后速度滞留一段再衰减恢复；向上翻页同理（向上加速/上浮）；
- [ ] 素材自然滚动区内持续滚动时粒子随滚动速度获得呼应（强度随滚动速度），停止后同样滞留衰减；
- [ ] 粒子总数上限、`document.hidden` 暂停、token 取色等既有口径不变；
- [ ] `prefers-reduced-motion: reduce` 时（含运行时切换）：公开站氛围层冲量加速与滞留照常启用，粒子全上限/明灭与常规一致。

#### F5 档案五屏（P1~P5）

**描述**: 档案模块拆为 5 个整屏子页，布局为**立绘 + 内容左右分栏**：单数页（P1/P3/P5）立绘在左、内容在右；双数页（P2/P4）立绘在右、内容在左。移动端为立绘在上、内容在下的纵向布局。5 屏内容（复用现 `/about` 五组内容，文案不变）：

- P1「信息・Profile」：枝堇个人信息（现信息卡内容：本名/生日/种族/身高/身份/所属/粉丝勋章/应援色/代表 Emoji/Live2D）；
- P2「设定・Story」：枝堇相关设定（现设定故事：出道设定 + VirtuaReal 预告专栏节选，纸页卡片样式可保留）；
- P3「喜好・Taste」：枝堇喜好（现喜好标签组：喜欢/不擅长/常玩/常读常看/常听/偏好类型）；
- P4「历程・Journey」：直播经历（现藤蔓历程时间轴）；
- P5「轶闻・Trivia」：轶闻（现逸闻卡片）。

每屏需在小一屏内容量下保持呼吸感：内容区可内部收缩居中，超出视口的内容按「优先桌面一屏放下、移动端允许屏内微调」处理，不产生屏内滚动条（以实现定稿为准）。立绘素材在现有立绘/插画素材中选取，各屏可有差异（如 P1 用立绘②、P2 用氛围插画等，以实现定稿为准）。官方外链按钮组置于 P5 轶闻屏末尾。

**验收标准**:

- [ ] 档案 P1~P5 按上述内容与顺序展示；
- [ ] 单数屏立绘在左、双数屏立绘在右；移动端立绘在上、内容在下；

## 四、非功能需求

### 4.1 性能

- 翻页转场、视差、粒子仅使用合成层属性（`transform`/`opacity`）与 Canvas 2D，不触发布局；
- 动画循环用 `requestAnimationFrame`，页面隐藏（`document.hidden`）时暂停；组件卸载完整清理监听与 rAF；
- 整页容器首屏直出内容为首屏静态 HTML（SSG），翻页轨道不动态插入阻塞资源；各屏图片懒加载（首屏立绘 `priority` 口径不变）；
- 不新增任何运行时依赖；
- 无 CLS：各屏高度由 `svh` 决定，翻页不产生布局偏移。

### 4.2 可访问性与减少动态效果（reduced-motion：公开站氛围层不降级）

- 本站为展示向粉丝站，氛围动效（视差/粒子/翻页转场/冲量）为核心卖点：**公开站氛围层对 `prefers-reduced-motion: reduce` 不降级**，reduced 用户体验与常规一致（完整视差幅度、粒子全上限/明灭/冲量、整页 rAF 转场与粒子耦合）。此口径仅限公开站氛围层；后台 `/backdoor` 仍严格执行 `docs/engineering/frontend-rules.md` 的 reduced-motion 规范。
- 键盘可达：方向键/PageUp/PageDown/Home/End 翻页；导航与指示器跳转键盘可达；Lightbox、当日详情弹层既有键盘口径不变；
- 粒子、立绘、转场装饰元素 `aria-hidden` + `pointer-events-none`；各屏标题层级正确（每屏有可被读屏定位的标题）。

### 4.3 兼容性

- 桌面现代浏览器（Chrome/Firefox/Safari 最近两个大版本）；移动端 Safari 与 Android Chrome（触屏滑动手势）；
- wheel/touch/keyboard 输入均做特性检测与被动监听，不阻止页面内既有交互（Lightbox、弹层、日历详情）；
- 纯静态导出（`output: "export"`）：首屏 SSG 直出，翻页行为仅在客户端 hydration 后启用，SSG 产物不含滚动位置状态（防 hydration 不一致）。
