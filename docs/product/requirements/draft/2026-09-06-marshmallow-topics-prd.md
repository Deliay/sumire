# 棉花糖（提问箱）

**功能名称**: 棉花糖（Marshmallow Topics）
**PRD 版本**: v1.2
**创建日期**: 2026-09-06
**作者**: sumire workflow

## 一、背景与目标

### 1.1 背景

主播与粉丝之间常见的互动形式之一是「提问箱」（棉花糖）：运营者开设一个征集主题，访客匿名投递内容，运营者在后台审阅、挑选并在直播中以幻灯片形式展示。本站现态无任何提问箱能力。本期从零新增「棉花糖」功能：后台「棉花糖」板块负责主题的创建与管理、投递内容的审阅与采用、幻灯片放映；公开站新增收集页供访客投递；投递内容经 AI 前置审核，可疑内容默认隐藏。

### 1.2 目标

- 后台新增「棉花糖」板块（`/backdoor/topics`）：主题卡片列表、新建主题、主题详情（棉花糖列表 + 采用管理）、停止/继续收集、归档、修改；
- 每个主题有一个对外收集页（`/topics/{topic-id}`）：展示主题信息并提供 Markdown 编辑器供访客投递，提交完成后展示提交完成结果页；
- 投递频率受三重限制（localStorage 标识 + 访客 Cookie + IP 地址），超限提示操作频率过快；
- 主题可启用 AI 前置审核（默认启用）：投递内容经异步审核，可疑内容在后台默认覆盖隐藏；
- 被「采用」的棉花糖可在独立幻灯片页（`/backdoor/topics/{topic-id}/presentation`）逐条放映。

### 1.3 成功标准

- [ ] 后台左侧导航出现「棉花糖」入口，进入主题卡片列表页，可新建主题（5 字段 + AI 审核开关），状态按开始/结束时间自动判定；
- [ ] 主题详情页可审阅棉花糖、采用/取消采用、对 AI 判定可疑内容经确认后查看（持久化）、对审核中内容可提前查看（不持久化）；
- [ ] 公开收集页可投递棉花糖，Markdown 编辑器可用，首次投递同步颁发访客 Cookie，三重频率限制生效，提交完成后展示仅含成功结果的结果页；
- [ ] 启用 AI 审核的主题，投递内容异步审核，可疑内容默认隐藏并展示拒绝原因；
- [ ] 幻灯片页逐条展示已采用棉花糖，支持翻页、字号调节与首次引导。

## 二、用户分析

### 2.1 目标用户

- 后台管理员（superadmin / admin）：主题创建者、棉花糖审阅与采用者、幻灯片放映操作者；
- 公开站访客（无需登录）：在收集页向主题投递棉花糖。

### 2.2 用户场景

| 场景 | 用户角色 | 目标 | 痛点（现况） |
|------|----------|------|------|
| 开设提问箱主题 | admin | 创建一个带起止时间与字数限制的征集主题 | 无此能力 |
| 访客投递 | 访客 | 用 Markdown 向主题投递内容并得到明确的成功反馈 | 无此能力 |
| 内容审核 | admin | 有害内容默认隐藏，不直接暴露给审阅者 | 无审核机制 |
| 直播展示 | admin | 把采用的棉花糖以幻灯片逐条展示 | 无此能力 |

## 三、功能需求

### 3.1 功能概述

本期新增「棉花糖」提问箱功能，横跨后台、公开站与服务端：

1. 后台「棉花糖」板块：主题卡片列表 + 新建主题 + 主题详情（棉花糖审阅/采用）+ 幻灯片放映页；
2. 公开收集页 `/topics/{topic-id}`：展示主题信息 + Markdown 编辑器投递 + 提交完成结果页；
3. 服务端：主题与棉花糖的存储、公开投递接口、三重频率限制（localStorage 标识 + 访客 Cookie + IP）、AI 前置审核（Redis 队列异步执行，结构化输出 filtered / filteredReason）。

### 3.2 功能列表

#### F1 后台「棉花糖」板块与主题卡片列表

**描述**:

- 后台左侧导航（SideNav）新增「棉花糖」入口，href 为 `/backdoor/topics`，superadmin / admin 可见；
- `/backdoor/topics` 展示「棉花糖主题列表」，为**卡片列表**，并提供「新建主题」入口；
- 卡片第一行：左侧展示「标题」，右侧展示「状态」（未开始 / 进行中 / 已结束）；
- 卡片第二行为操作按钮：「停止收集」/「继续收集」（同一按钮随状态切换）、「归档」、「修改」；
- 卡片其余区域点击后进入该主题的后台详情页（`/backdoor/topics/{topic-id}`）；
- 状态判定：当前时间早于开始日期为「未开始」；处于起止区间内且未被手动停止为「进行中」；超过结束日期或被手动停止为「已结束」。

**验收标准**:

- [ ] 导航出现「棉花糖」（superadmin / admin），点击进入卡片式主题列表页；
- [ ] 卡片按上述结构展示标题、状态与三个操作位；
- [ ] 点击卡片非按钮区域跳转 `/backdoor/topics/{topic-id}`；
- [ ] 状态与起止时间/手动停止的对应关系正确。

#### F2 新建 / 修改主题

**描述**:

- 「新建主题」表单字段：**标题**、**描述**、**开始日期**、**结束日期**、**字数限制**（5 个字段）；
- **启用AI前置审核**为单选勾选框，**默认勾选**；勾选后该主题的投递内容启用 AI 自动审核；
- 每条棉花糖带「AI 审核状态」字段，新投递默认为「审核中」（启用 AI 审核时）；
- 「描述」使用 Markdown 编辑器（见 F7）；
- 字数限制最小 **100 字**、最多 **10000 字**；
- 提交后若开始时间早于当前时间，主题状态自动为「进行中」，否则为「未开始」；
- 「修改」入口（卡片与详情页均有）复用同一表单编辑既有主题。

**验收标准**:

- [ ] 5 个字段全部必填，缺任一项无法提交；
- [ ] 字数限制 <100 或 >10000 时拒绝提交并提示；
- [ ] 描述字段为 Markdown 编辑器；
- [ ] 启用AI前置审核默认勾选，可取消；
- [ ] 新建后状态按开始时间与当前时间关系自动判定；
- [ ] 修改表单可编辑并保存主题字段。

#### F3 停止收集 / 继续收集与归档

**描述**:

- 卡片上的「停止收集」点击后该主题停止接收新投递，状态视为「已结束」，按钮切换为「继续收集」；
- 「继续收集」恢复接收投递（若已超过结束日期，状态仍为「已结束」，需先修改结束日期）；
- 「归档」将主题从默认列表中收起（归档主题不再出现在卡片列表默认视图，数据保留）；
- **「已归档主题」入口**（v1.2 新增）：列表页提供「主题 / 已归档主题」视图切换，已归档视图展示全部已归档主题；已归档主题可「恢复」（恢复后回到默认列表，状态按起止时间重新判定）、可进入详情页查看，但不可修改或采用，也可进入幻灯片查看。

**验收标准**:

- [ ] 停止收集后公开收集页不再接受投递并给出提示；
- [ ] 继续收集后（且仍在起止区间内）恢复接收投递；
- [ ] 归档后主题不出现在默认卡片列表；
- [ ] 「已归档主题」视图展示全部已归档主题；恢复后主题回到默认列表且可正常管理；
- [ ] 已归档主题详情页只读（无修改/停止继续收集/采用入口），幻灯片可正常查看。

#### F4 主题详情页

**描述**:

- 路由 `/backdoor/topics/{topic-id}`；
- 页头：以主题「标题」为大标题；「描述」渲染 Markdown，**最多显示 3 行**，支持折叠/展开，**默认折叠**；
- 工具按钮：「分享」（打开浮层展示投递链接 + 二维码 + 下载 PNG）、「幻灯片」（打开 `/backdoor/topics/{topic-id}/presentation`）、「开始/结束收集」（与 F3 同语义）、「修改主题」；
- 页面剩余区域为一个占满剩余高度、容器内部滚动的「棉花糖」列表；
- 每条棉花糖占满整个宽度，高度不限（按内容自适应）；
- 每条棉花糖带工具按钮「采用」：点击后该条变灰并展示「已采用」标记，按钮变为「取消采用」；取消采用恢复原状。

**验收标准**:

- [ ] 页头标题/描述/工具按钮齐全，描述折叠默认收起、可展开至完整内容；
- [ ] 棉花糖列表在容器内部滚动，条目全宽、高度自适应；
- [ ] 「采用」/「取消采用」切换即时生效并持久化，已采用条目呈灰色并标记「已采用」。

#### F5 AI 审核覆盖层

**描述**:

针对启用 AI 审核的主题中的每条棉花糖：

- **审核未通过**（数据带 filtered 标记与 filteredReason）：默认叠加覆盖层，文案「这个棉花糖可能会有有害内容，AI拒绝原因：{filteredReason}」，并提供「显示这条棉花糖」按钮；点击后才可查看内容，且该操作**持久化**（`ignore_ai_filter=true`，之后不再覆盖）；
- **审核中**：覆盖层提示「这条内容AI正在审核中」，附带「提前查看」按钮；点击仅临时展示内容，**不做任何持久化**；
- 审核失败（如 AI 服务异常）同样按未通过口径展示拒绝原因；
- 主题**未启用** AI 审核时，不展示任何覆盖层。

**验收标准**:

- [ ] 未通过条目默认被覆盖层遮挡，展示拒绝原因；点击「显示这条棉花糖」后可见内容且刷新后仍可见（已持久化）；
- [ ] 审核中条目展示审核中提示；「提前查看」临时展示，刷新后恢复覆盖；
- [ ] 未启用 AI 审核的主题无任何覆盖层。

#### F6 公开收集页

**描述**:

- 路由 `/topics/{topic-id}`，对外公开、无需登录；
- 展示主题的「标题」、「描述」（渲染 Markdown）、「状态」、「开始/结束时间」（与主题详情页同口径）；
- 提供 Markdown 编辑器（见 F7）供投递棉花糖；
- **提交前弹窗**告知用户：「内容会被AI审核，如果有有害信息，则会判定为未通过AI审核，默认隐藏」，确认后才提交；
- **访客 Cookie**：访客首次访问收集页接口时，服务端通过 `Set-Cookie` 同步颁发一个访客标识 Cookie（HttpOnly），作为频率限制维度之一；
- 频率限制（任一超限即拒绝并提示「操作频率过快」）：
  - 客户端标识：首次访问时在 localStorage 颁发一个标识，**每个标识 1 分钟限 1 条、1 小时限 5 条**；
  - 访客 Cookie：服务端颁发的访客标识 Cookie，**每个 Cookie 标识 1 分钟限 1 条、1 小时限 5 条**；
  - IP 地址：服务端记录提交者 IP，**每个 IP 1 分钟限 1 条、1 小时限 5 条**；
- 投递内容长度不得超过主题的字数限制；
- **提交完成结果页**：提交完成后切换为「提交完成」结果视图——仅告知是否提交成功（如「提交成功，感谢你的棉花糖」），**不展示 AI 审核状态等任何审核相关字段**；结果视图提供「**查看进行中的棉花糖**」入口（跳转 `/topics` 进行中列表页；v1.2 起不再提供「再投一条」）；
- 主题未开始、已结束或已归档时不接受投递，并展示对应状态提示。

**验收标准**:

- [ ] 收集页正确展示标题/Markdown 描述/状态/起止时间；
- [ ] 提交前出现 AI 审核告知弹窗，确认后提交成功；
- [ ] 首次访问收集页接口后响应带访客标识 Cookie（HttpOnly），后续请求自动回带；
- [ ] 同一 localStorage 标识 1 分钟内第 2 条、1 小时内第 6 条被拒绝并提示「操作频率过快」；
- [ ] 同一访客 Cookie 标识的上述限制同样生效（与 localStorage 标识、IP 限制独立计算）；
- [ ] 同一 IP 的上述限制同样生效（与标识类限制独立计算）；
- [ ] 提交成功后展示「提交完成」结果视图，视图与提交响应中均不出现 AI 审核状态等字段；
- [ ] 超过字数限制的投递被拒绝并提示；
- [ ] 未开始/已结束/已归档主题投递被拒并展示状态提示。

#### F7 Markdown 编辑器

**描述**:

- 用于主题「描述」编辑（F2）与收集页投递（F6）两处；
- 提供类似富文本编辑的功能按钮（如加粗、斜体、标题、列表、链接、引用、代码块等），体验尽量接近富文本编辑器；可采用开源库实现。

**验收标准**:

- [ ] 编辑器带功能按钮工具栏，点击按钮可插入对应 Markdown 语法；
- [ ] 编辑内容以 Markdown 文本保存，渲染侧正确呈现。

#### F8 幻灯片放映页

**描述**:

- 独立页面，路由 `/backdoor/topics/{topic-id}/presentation`；从主题详情页「幻灯片」按钮打开；
- 仅展示该主题被标记为「采用」的棉花糖；
- 每条棉花糖占满整个高度，支持 Y 向滚动（内容超高时条目内部可滚动），**宽度限制为 max-width: 50%**；
- 页面左侧、右侧各有一个占满高度的按钮（小于 / 大于符号图标），点击切换上一条 / 下一条；
- 页头含主题「标题」与「描述」（Markdown 渲染，最多 3 行，支持折叠，默认折叠）；
- 工具栏可调节棉花糖字体大小，调节结果保存到 localStorage；
- 第一次打开（以 localStorage 记录为准）展示一个遮盖层，引导用户认知操作逻辑（左右翻页、滚动、字号调节）。

**验收标准**:

- [ ] 仅已采用棉花糖进入放映；条目满高、Y 向可滚动、max-width 50%；
- [ ] 左/右全高按钮切换上一条/下一条（首条无前、末条无后时对应按钮不可用）；
- [ ] 字号调节即时生效，刷新后保留；
- [ ] 首次打开出现引导遮盖层，关闭后不再出现（localStorage 记录）；
- [ ] 页头描述折叠行为与详情页一致。

#### F9 公开「进行中的棉花糖」页与顶部导航入口（v1.2 新增）

**描述**:

- 面向游客的公开页面，路由 `/topics`（与收集页同路由：无 `id` 查询串时为本页，有 `id` 时为收集页）；
- 展示进行中（未归档且处于收集状态）的棉花糖主题列表：标题、描述（截断展示）、起止时间；点击主题进入对应收集页投递；
- 顶部导航栏（NavBar）新增「棉花糖」入口，点击跳转本页；导航栏固定于视口顶部、**不随页面滑动**；仅 API 已配置时展示该入口。

**验收标准**:

- [ ] `/topics`（无 id）展示进行中主题列表，未开始/已结束/已归档主题不出现；
- [ ] 点击列表中主题进入对应收集页，可正常投递；
- [ ] 顶部导航出现「棉花糖」入口并跳转本页；导航栏页面滚动时保持固定；
- [ ] 未配置 API 形态下导航无「棉花糖」入口、`/topics` 按既有口径 404。

### 3.3 页面/界面描述

| 页面 | 描述 | 关键元素 |
|------|------|----------|
| `/backdoor/topics` | 主题卡片列表 | 「主题 / 已归档主题」视图切换、卡片（标题/状态/操作按钮）、「新建主题」入口、新建/修改表单弹窗（含 Markdown 编辑器与 AI 审核勾选） |
| `/backdoor/topics/{topic-id}` | 主题详情页 | 大标题 + 可折叠 Markdown 描述、工具按钮（幻灯片/开始结束收集/修改主题）、内部滚动棉花糖列表（采用切换、AI 覆盖层）；已归档主题只读 |

| `/topics` | 公开「进行中的棉花糖」页 | 进行中主题卡片列表（标题/描述截断/起止时间），点击进收集页；顶部导航「棉花糖」入口 |

### 3.4 异常与边界情况

| 情况 | 预期行为 |
|------|----------|
| 未配置 API（`API_CONFIGURED === false`） | 按既有构建时守卫口径处理，不展示占位入口 |
| 未登录 / 会话失效（后台页） | 沿用 `(dashboard)/layout.tsx` 会话守卫口径 |
| member 角色访问 `/backdoor/topics*` | 不展示导航入口；直达按权限不足处理 |
| 开始日期晚于结束日期 | 表单校验拒绝并提示 |
| 已超过结束日期点击「继续收集」 | 状态仍为「已结束」，提示需先修改结束日期 |
| 主题不存在（收集页/详情页/幻灯片） | 展示不存在提示，不报错崩溃 |
| 投递内容超过字数限制 | 拒绝并提示 |
| 频率超限（localStorage 标识、访客 Cookie 或 IP 任一） | 拒绝并提示「操作频率过快」 |
| 访客 Cookie 被禁用或清除 | 服务端重新颁发新 Cookie；该维度视为新访客，其余维度限制仍生效，不报错 |
| AI 服务不可用 / 审核失败 | 条目按未通过口径覆盖，展示拒绝原因；不阻断投递本身 |
| 未启用 AI 审核的主题 | 无异步审核、无覆盖层 |
| 无已采用棉花糖时打开幻灯片 | 展示空态提示 |
| localStorage 损坏（标识/字号/引导记录） | 回退默认（重新颁发标识 / 默认字号 / 视为首次） |

## 四、非功能需求

### 4.1 性能

- 棉花糖列表按主题分页/增量加载，单主题量级预期百级，无需虚拟化；
- AI 审核异步执行，不阻塞投递响应；
- 频率限制计数走 Redis，单次请求 O(1)。

### 4.2 安全性

- 后台全部管理端点服务端强制鉴权（superadmin / admin）；公开端点仅「读主题公开信息」与「投递」两个；
- 投递内容服务端存储与渲染时按 Markdown 白名单渲染（禁原始 HTML 注入），防 XSS；
- 提交响应不携带审核状态等内部字段，访客侧不暴露审核机制细节；
- 访客标识 Cookie 为 HttpOnly，前端脚本不可读；
- AI 凭据仅存于服务端环境变量，前端不可见；
- 提交者 IP 仅用于频率限制与审计，不对外展示。

### 4.3 兼容性

- 同后台既有口径：桌面现代浏览器最近两个大版本；幻灯片页桌面优先；
- 公开收集页兼顾移动端窄屏布局。

### 4.4 可访问性

- 弹窗遵循既有弹层口径（焦点管理、Esc 关闭）；
- 翻页按钮提供可访问名称；覆盖层按钮可键盘触达。

## 五、依赖与约束

### 5.1 依赖

- 既有基础设施：会话鉴权与 `requireRole`、Redis（会话/限速，本期复用同一实例做审核队列）、MongoDB（新增集合）、Aspire 编排；
- 新增外部依赖：AI 审核服务（OpenAI 兼容 / Claude），经 `SUMIRE_REVIEW_AI_` 前缀环境变量配置；审核模型可选由 `SUMIRE_REVIEW_AI_MODEL` 指定，未设置回退各分支默认。

### 5.2 约束

- 契约先行：新增 `contract/topics.openapi.yaml` 为单一事实源，实现与 tests/api 均以契约为准；
- AI 审核必须异步（Redis 队列），不得同步阻塞投递；
- 前端 Tailwind v4 token 色，禁止硬编码色值；后台视觉按 `docs/design/03-backdoor-design.md`；
- 未上线功能不得在 UI 中显示占位入口；
- 分支命名 `<type>/<slug>`：需求总分支 `prd/marshmallow-topics`。
