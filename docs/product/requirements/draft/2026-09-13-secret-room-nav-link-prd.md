# 导航「小密室」外链

**功能名称**: 导航「小密室」外链（Secret Room Nav Link）
**PRD 版本**: v1.0
**创建日期**: 2026-09-13
**作者**: sumire workflow

## 一、背景与目标

### 1.1 背景

枝堇的粉丝内容除本站（堇色书屋）外，另有「小密室」站点 `https://sumire.icu`。目前站内无任何通往小密室的入口，访客需要自行记住或从其他渠道获取该地址。需要在首页顶部导航栏（全站固定 NavBar）增加「小密室」入口，点击后新窗口打开，避免打断访客在本站的浏览。

导航现态以 `docs/product/spec/site-pages.md` 与 `apps/bookstore/components/NavBar.tsx` 为准：导航项由基础锚点项（主页/档案/素材/日历）、「棉花糖」独立路由项与工具集注册表项组成，全部为站内导航（锚点或独立路由）。

### 1.2 目标

- 顶部导航栏新增「小密室」链接，指向 `https://sumire.icu`；
- 点击后在新窗口/新标签页打开，当前页停留不动；
- 桌面端导航与移动端折叠菜单均展示该入口。

### 1.3 成功标准

- [ ] 桌面端导航与移动端折叠菜单均出现「小密室」链接，href 为 `https://sumire.icu`；
- [ ] 点击后新窗口打开目标站（`target="_blank"`），且带 `rel="noopener noreferrer"`，当前页不跳转；
- [ ] 未配置 API（`NEXT_PUBLIC_API_BASE_URL` 为空）时该入口依然显示（纯静态外链，不参与 API 配置降级）；
- [ ] 站内既有导航项的锚点跳转、选中态高亮与 deck 翻页行为零回归。

## 二、用户分析

### 2.1 目标用户

- 站点访客（未登录）：希望从本站前往小密室的用户。

### 2.2 用户场景

| 场景 | 用户角色 | 目标 | 痛点（现况） |
|------|----------|------|------|
| 前往小密室 | 访客 | 从本站一键打开小密室 | 站内无入口，需自行记忆地址或从站外渠道进入 |

## 三、功能需求

### 3.1 功能概述

本期在公开站顶部导航栏（`NavBar`）新增一个纯静态外链项「小密室」，指向 `https://sumire.icu`，新窗口打开。纯前端变更：无 API、无契约、无数据库变更。

### 3.2 功能列表

#### F1 导航「小密室」外链

**描述**:

- 导航栏新增链接项「小密室」，href 固定为 `https://sumire.icu`；
- 以 `<a target="_blank" rel="noopener noreferrer">` 形态渲染，点击在新窗口/新标签页打开，当前页不发生跳转；
- 桌面端导航列表与移动端折叠菜单均包含该项；
- 该项为外链：不参与站内锚点/路由选中态（永不呈现高亮选中），不触发首页 deck 翻页事件；
- 位置固定于导航列表末尾（基础锚点项、「棉花糖」、工具项之后），不受工具集注册表动态项影响；
- 恒显示：不依赖 `API_CONFIGURED`，未配置 API 时依然存在。

**验收标准**:

- [ ] 桌面端渲染「小密室」链接，`href="https://sumire.icu"`、`target="_blank"`、`rel` 含 `noopener` 与 `noreferrer`；
- [ ] 移动端打开折叠菜单后同样存在该链接，属性一致；
- [ ] 任意路由（首页及各内容页）下「小密室」均不呈现选中态高亮（无 `aria-current`）；
- [ ] 首页内点击「小密室」不派发 `NAVIGATE_EVENT`、不改变 `location.hash`、不触发 deck 翻页；
- [ ] 未配置 API 时「小密室」仍渲染；
- [ ] 既有导航项（主页/档案/素材/日历/棉花糖/工具项）的 href 形态、选中态与点击行为不变。

### 3.3 页面/界面描述

- 「小密室」文字链接，字号/字距/颜色与既有导航项一致（`text-sm tracking-widest`，未选中 `text-ink-dim hover:text-ink`）；
- 因永不选中，不呈现选中态主色；外链无额外线框/图标装饰（保持导航视觉一致性，可由实现评审微调）。

### 3.4 异常与边界情况

| 情况 | 预期行为 |
|------|----------|
| 目标站不可达 | 浏览器新窗口正常报错页，本站无感知（纯外链，无健康检查） |
| 未配置 API | 「小密室」照常显示（纯静态，不走 `API_CONFIGURED` 降级） |
| 首页点击该项 | 新开窗口，本站 hash 与 deck 位置不变 |
| 移动端菜单展开点击 | 新开窗口；菜单开合状态由既有逻辑处理，可保持现状 |

## 四、非功能需求

### 4.1 性能

- 无运行时请求、无额外依赖；SSG 输出不变（链接地址硬编码，构建期确定）。

### 4.2 安全性

- 外链必须带 `rel="noopener noreferrer"`，防止新窗口经 `window.opener` 反向操控本站；
- 目标地址硬编码，不接受任何运行时输入，无注入面。

### 4.3 兼容性

- 纯新增导航项，不改既有导航行为；桌面与移动端断点表现与既有导航一致。
