# 后台鉴权与用户管理 Spec

后台位于 `/backdoor` 路由区，供运营人员管理用户、直播计划与弹幕。不开放注册，账号由有权限的管理员创建。

## 存在性与入口

- 仅在 API 配置时（`API_CONFIGURED`）存在；未配置时整个 `/backdoor` 呈现站点 404，且不发任何 `/api/*` 请求。
- 公开站不提供指向后台的链接；后台靠直接访问 URL 进入。

## 角色模型

三级角色，权限从高到低：`superadmin`（超管）> `admin`（管理员）> `member`（成员）。

| 能力 | superadmin | admin | member |
|---|---|---|---|
| 仪表盘、直播计划查看、弹幕查看 | ✓ | ✓ | ✓ |
| 直播计划增/改/删、弹幕已读管理 | ✓ | ✓ | — |
| 用户管理（列表 + 建号） | ✓（可建任意角色） | 仅可建 member | — |

导航按角色过滤：「用户管理」仅 superadmin 可见；其余角色直接访问用户管理页会被引导回仪表盘。

## 登录

- 登录页提交账号密码；成功进入仪表盘。
- 失败统一提示「账号或密码错误」，不区分账号不存在与密码错误（防枚举），清空密码框并聚焦。
- 触发限速（5 次/分钟/IP）时单独提示「尝试过于频繁」。
- 会话有效期 7 天，有效期内持续使用自动续期；仪表盘展示「本次登录有效期至 …」提示。
- 登出无二次确认，登出后回到登录页，再访问后台需重新登录。

## 强制改密

- 所有新建账号（含种子超管）初始状态为「必须修改密码」。
- 该状态登录后被锁定在改密页（"无路可去"），无法进入后台其他页面；改密成功后解锁并进入仪表盘，会话保持有效。
- 密码规则：≥12 位，含字母、数字、符号；新密码不能与原密码相同；改密需验证原密码。

## 用户管理（仅 superadmin）

- 用户列表展示用户名、角色、创建时间。
- 创建用户：选择角色（admin 通过接口建号时仅可建 member）、设置初始密码；用户名重复被拒绝。新用户首次登录走强制改密流程。

## 视觉与文案

- 后台与公开站共享设计语言（深色底、应援色主按钮），但不使用氛围动效。
- 守卫加载态为静态紫花微光点 +「正在确认身份…」。
- 文案沿用「书屋的里屋 / 钥匙」隐喻（如强制改密提示「请先换一把自己的钥匙」）。
