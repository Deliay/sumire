# 公开日历 Spec

日历页 `/calendar` 面向所有访客展示直播安排，数据来自两类来源的混合：人工维护的直播计划（stream-plans）与实际直播历史（live-history）。

## 存在性

- 仅在 API 配置时（`API_CONFIGURED`）存在；未配置时 `/calendar` 呈现站点 404，导航与首页不出现入口。

## 数据合并规则

- 计划按当前展示区间拉取（翻月/翻周时按新区间重拉）；历史直播仅在首次加载拉一次全量，失败时静默降级为只展示计划。
- **月视图按展示网格范围取数**（公开页与后台 `/backdoor/schedule` 同组件同口径）：拉取范围为月视图实际展示的 6×7 网格**首格~末格**（周一开头，跨月补位），例如 2026-08 网格为 2026-07-27 ~ 2026-09-06；首屏与翻月均按此口径。周视图（<640px）仍按周一~周日取数。
- 跨月补位格由此可展示日程摘要（沿用月视图「至多 2 条 + +N」收口），其**弱化样式（`opacity-35`）与不可点击口径不变**。
- 历史记录按开播时间（startDate）的**本地时区**归入开播当日（跨天直播归开播日）。
- 缺 title 或 startDate 的历史条目丢弃；时间戳在未来的历史条目（上游异常）不纳入。
- 计划与历史按「日期 + 开始时间」升序混排，同日同时不去重。

## 视图与交互

- 桌面（≥640px）：周一开头的固定 6×7 月网格；每日最多显示 2 条摘要，超出以「+N」收口。
- 移动（<640px）：自动切换为周视图——单周 7 天纵向列表（每日最多 4 条），支持周切换与「回到今天」。
- 时间感表达：今天以 flower 描边 + 小花点标示；过去的日子 60% 透明度弱化；历史条目恒弱化并以藤蔓色点区分来源；补位格 35% 透明不可点。
- 空月照常渲染，不显示额外提示。
- 点击某天弹出日详情浮层（只读）：条目按时间升序，历史条目标注「实际播出」与结束时间「至 HH:mm」；空日文案「这一天书屋静悄悄的。」；点击遮罩关闭。

## 变体（`CalendarView variant`）

- **默认 `panel`**：后台 `/backdoor/schedule` 与既有调用不传 variant，DOM 与样式逐位保持现态（圆角小字、头部小翻月按钮），后台零回归。
- **`immersive`**（公开 `/calendar` 与首页日历站）：直角中号字（DayCell 去 `rounded-md`，日期 `text-base` 量级、摘要 `text-sm` 量级），全幅占满屏宽；翻月按钮改为日历左右两侧**高度占满的竖条**（`absolute inset-y-0`，图标 + hover token 色），头部仅保留月份标题；支持**横向拖拽翻月**（横向位移累积超阈值约 60px 触发，左拖下月右拖上月，release 归零），拖拽超阈值时置 `isDragging` 抑制日期点击；网格区 `touch-action: pan-y` 保留纵向滚动、`pointer` 监听不 `preventDefault`。周视图分支不渲染拖拽/竖条按钮、布局不变。

## 首页「今日日程」入口

首页不再内嵌「本周日程」大卡，改为轻量「今日日程」组件：仅当天计划（`HH:mm 主题`），无计划展示「今日暂无安排」，失败静默为空态；仅在 API 配置时渲染。规则见 [site-pages.md](site-pages.md)。日历完整视图仅经 `/calendar` 访问。
