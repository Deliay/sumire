# 弹幕看板 Spec

后台 `/backdoor/danmaku` 聚合展示直播间实时与历史事件，供运营人员查看与做已读管理。数据来自服务端代理的内网直播事件流。

## 事件类型与展示

四类事件：弹幕（danmaku）、醒目留言（super_chat）、礼物（gift）、上船（guard_buy）。

- 发送者信息：昵称（含罗马音标注）、头像、粉丝牌（按牌子颜色渲染）、上船等级挂件（舰长/提督/总督本地素材）；点击发送者新开其 B 站空间。
- 金额分档配色：<10 灰 / 10–99 蓝 / 100–500 金 / >500 红。
- 弹幕中的表情以图片展示；文字弹幕支持折叠（见下）。
- 留言内容同样带罗马音标注。

## 栏位布局

- 信息流按「栏」组织，每栏勾选类型组合（至少一种），可选择同栏混排或按类型分节。
- 默认 3 栏：礼物 | 上船+SC 分节 | 弹幕；2 栏预设为上船+SC 分节 | 礼物+弹幕混排。
- 栏数与每栏配置持久化在浏览器 localStorage（跨标签页同步）；配置损坏时回退默认 3 栏。
- 视口自适应：窄屏（<640px）恒单栏全类型，中屏（640–1023px）最多 2 栏，宽屏（≥1024px）2–3 栏；页头栏数选择器可切换预设，视口夹取导致的覆盖不回写存储。
- 支持全屏模式（覆盖顶栏/侧栏，独立页头可退出）。

## 礼物金额筛选

- 顶层工具区提供「礼物筛选」按钮，点击弹出筛选面板（滑动条 0–100 步进 0.1 + 输入框双向同步）。
- 阈值持久化在浏览器 localStorage `danmaku-backdoor.gift-min-price`（JSON number），损坏回退 0（不筛选）。
- 阈值 > 0 时按钮呈激活态；阈值变化仅重载礼物分节（页码重置为 1），非礼物节不受影响。
- SSE 实时到达的礼物事件，金额低于当前阈值时前端直接丢弃，不插入列表。

## 信息流行为

- 首屏按「栏 × 类型」分节加载历史事件（每节独立检索、分页、错误重试）；滚动接近底部自动加载下一页。
- 实时事件经 SSE 推送，插入到所有包含该类型的栏顶部；列表顶部插入时滚动位置锚定不跳动，远离顶部时显示「回到顶部」。
- 实时插入的视觉反馈：新条目播放入场动画（淡入+下落，100ms），贴顶跟随时同列表既有条目以平移过渡（100ms）让位；离开顶部时平移过渡禁用，由滚动锚定补偿瞬时保持内容（避免补偿与过渡叠加闪回）；历史首屏加载与分页 append 不播放入场动画。
- 断线自动重连，连接状态以提示条暴露。

## 弹幕合并（折叠）

弹幕合并有开关：栏头工具区提供「弹幕合并」开关，默认关闭；关闭时弹幕逐条原样展示，不折叠、不显示计数。

- 开关状态持久化在浏览器 localStorage `danmaku-backdoor.merge-danmaku`（JSON boolean），损坏回退关闭；切换即时全局生效（所有栏的弹幕分节），不重新检索历史数据。
- 开启后：相同内容合并为一条并累计计数。表情弹幕以表情图为键；文字弹幕以「最长非重复子串」为键（如「妈妈妈妈」折叠为「妈」）；折叠代表行锚定在原内容的末次出现位置，新增同类弹幕只累加计数、不移动位置。

## 已读管理（admin+）

- 双击 SC / 礼物 / 上船条目切换已读状态，操作乐观更新、失败回滚并提示；member 无任何已读交互。
- SC 留言正文（含罗马音）可鼠标拖选复制，留言文本上的选择/双击不触发已读切换；条目其余区域的双击已读行为不变。
- 「标记全部已读」仅支持 SC 与上船，有二次确认；语义为「该类型当前事件全部已读」（水位线只前进）。
- 实时到达的 SC / 上船打「New」标记，读后清除；「全部已读」清除同类型 New。
- 已读状态持久化在服务端，刷新后保持。

## 展示增强

- 礼物事件的 `gift.iconUrl` 为可选字段；服务端从上游 `data.img_basic` 透传，缺失或加载失败时隐藏图标。
- 上船条目按船型展示本地徽章与强调样式；未知等级回退上游名称且不显示徽章。
- 弹幕条目按发送者船型渲染淡色背景：舰长蓝 / 提督紫 / 总督红（对应 badge 色的 0.5% 透明度）；普通观众与未知等级无背景。
