# 弹幕看板 Spec

后台 `/backdoor/danmaku` 聚合展示直播间实时与历史事件，供运营人员查看与做已读管理。数据来自服务端代理的内网直播事件流。

## 事件类型与展示

四类事件：弹幕（danmaku）、醒目留言（super_chat）、礼物（gift）、上船（guard_buy）。

- 发送者信息：昵称（含罗马音标注）、头像、粉丝牌（按牌子颜色渲染）、上船等级挂件（舰长/提督/总督本地素材）；点击发送者新开其 B 站空间。
- 金额分档配色：<10 灰 / 10–99 蓝 / 100–500 金 / >500 红。
- 弹幕中的表情以图片展示；文字弹幕支持折叠（见下）。
- 留言内容同样带罗马音标注。
- 在线人数：弹幕看板页头标题后展示小字号文案「当前直播间在线 {online_count} 人」（普通/全屏页头）；数值直接取自看板唯一 SSE 连接（`/api/live-events/stream`）的 `online_rank_count` 命名帧 `payload.online_count`，5s 节流更新；挂载时 `GET /api/live-events?type=online_rank_count&page=1&pageSize=1` 首取仅作首屏兜底（至多 1 次，无数据则等首帧）；无数据或获取失败时不展示。

## 栏位布局

- 信息流按「栏」组织，每栏勾选类型组合（至少一种），可选择同栏混排或按类型分节。
- 默认 3 栏：礼物+上船混排 | SC | 弹幕；2 栏预设为上船+SC混排 | 弹幕+礼物混排。
- 栏数与每栏配置持久化在浏览器 localStorage（跨标签页同步）；配置损坏时回退默认 3 栏。
- 视口自适应：窄屏（<640px）恒单栏全类型，中屏（640–1023px）最多 2 栏，宽屏（≥1024px）2–3 栏；页头栏数选择器可切换预设，视口夹取导致的覆盖不回写存储。
- 支持全屏模式（覆盖顶栏/侧栏，独立页头可退出）。

## 礼物金额筛选

- 顶层工具区提供「礼物筛选」按钮，点击弹出筛选面板（滑动条 0–100 步进 0.1 + 输入框双向同步）。
- 阈值持久化在浏览器 localStorage `danmaku-backdoor.gift-min-price`（JSON number），损坏回退 0（不筛选）。
- 阈值 > 0 时按钮呈激活态；阈值变化仅重载礼物分节（页码重置为 1），非礼物节不受影响。
- SSE 实时到达的礼物事件，金额低于当前阈值时前端直接丢弃，不插入列表。

## SC 隐藏钢镚

- 顶部「标记已读」按钮组内提供「隐藏钢镚」开关（role=switch），全局作用于所有 SC 面板。
- 开启后，金额 <30 元的 SC 不展示，≥30 元正常显示；关闭后恢复全部显示。
- 纯前端展示过滤：历史 SC 已全量加载，切换即时生效、不重新检索；实时到达的低价 SC 在开启状态下同样不插入展示。
- 隐藏只影响「展示」，不影响已读状态、New 标记、SC 留言检索页。
- 开关状态持久化在浏览器 localStorage `danmaku-backdoor.hide-low-sc`（JSON boolean），损坏回退关闭（全部显示）。
- SC 事件缺金额字段（price 无/undefined）时按未知金额处理：不命中「<30 隐藏」判定，正常显示（保守展示）。

## 信息流行为

- 首屏按「栏 × 类型」分节加载历史事件（每节独立检索、分页、错误重试）；滚动接近底部自动加载下一页。
- 实时事件经 SSE 推送，插入到所有包含该类型的栏顶部；列表顶部插入时滚动位置锚定不跳动，远离顶部时显示「回到顶部」。
- 实时插入的视觉反馈：新条目播放入场动画（淡入+下落，50ms），贴顶跟随时同列表既有条目以平移过渡（50ms）让位；离开顶部时平移过渡禁用，由滚动锚定补偿瞬时保持内容（避免补偿与过渡叠加闪回）；历史首屏加载与分页 append 不播放入场动画。
- 断线自动重连，连接状态以提示条暴露。

## 弹幕合并（折叠）

弹幕合并有开关：栏头工具区提供「弹幕合并」开关，默认关闭；关闭时弹幕逐条原样展示，不折叠、不显示计数。

- 开关状态持久化在浏览器 localStorage `danmaku-backdoor.merge-danmaku`（JSON boolean），损坏回退关闭；切换即时全局生效（所有栏的弹幕分节），不重新检索历史数据。开关仅在勾选了弹幕类型的栏头工具区显示。
- 开启后：相同内容合并为一条并累计计数。表情弹幕以表情图为键；文字弹幕以「最长非重复子串」为键（如「妈妈妈妈」折叠为「妈」）；折叠代表行锚定在原内容的末次出现位置，新增同类弹幕只累加计数、不移动位置。

## 已读管理（admin+）

- 双击 SC / 礼物 / 上船条目切换已读状态，操作乐观更新、失败回滚并提示；member 无任何已读交互。
- SC 留言正文（含罗马音）可鼠标拖选复制，留言文本上的选择/双击不触发已读切换；条目其余区域的双击已读行为不变。
- 顶部「视图栏」左侧「标记已读」按钮组集中上船/SC 全部已读（admin+）与隐藏钢镚开关；二次确认语义不变（点击进入确认态，3s 超时复位，确认触发全部已读）；空间不足（窄视口或容器宽度不足）时折叠为单个「标记已读」触发钮，点击展开下拉菜单含各项操作，宽度恢复还原平铺；member 仅见隐藏钢镚开关。
- 栏头（FeedColumn）不再单独渲染上船/SC 全部已读按钮；其余栏头功能（弹幕合并、礼物筛选、配置栏位）不变。
- 实时到达的 SC / 上船打「New」标记，读后清除；「全部已读」清除同类型 New。
- 已读状态持久化在服务端，刷新后保持。

## 展示增强

- 礼物事件的 `gift.iconUrl` 为可选字段；服务端从上游 `data.img_basic` 透传，缺失或加载失败时隐藏图标。
- 上船条目按船型展示本地徽章与强调样式；未知等级回退上游名称且不显示徽章。
- 弹幕条目按发送者船型渲染淡色背景：舰长蓝 / 提督紫 / 总督红（对应 badge 色的 10% 透明度）；普通观众与未知等级无背景。

## 弹幕检索

侧栏导航提升为一级入口（`/backdoor/danmaku/search`），全角色可见，与弹幕看板并列。

- 顶部搜索输入框（300ms 防抖 + 回车立即搜索 + AbortController 取消旧请求）；
- 结果以卡片横向排布的换行瀑布流呈现，卡片宽度响应式（单列/双列/三列）；
- 按类型分发渲染：弹幕（DanmakuCard）、SC（SuperChatItem + 关键词高亮）、礼物（GiftItem）、上船（GuardItem），各自复用看板条目组件；
- SC 高亮：`SuperChatItem` 接受可选 `highlightKeyword` 入参，非空时留言命中子串以 `<mark>` 标签包裹显示；
- 分页加载：末尾「加载更多」按钮，加载完成后结果 append 追加；
- 三态反馈：加载中指示 / 无匹配弹幕 / 错误提示（含重试按钮）；
- 只读口径：检索结果不提供已读切换交互，与看板管理态解耦；
- 检索页对称提供「返回看板」链接；
- 时间格式：`MM/DD HH:mm` 本地化短格式（`formatOccurredAt` 口径）。

## SC/上船悬停胶囊栏

弹幕/弹幕混排栏内容区顶部新增悬停胶囊栏（仅勾选弹幕类型的栏挂载），SC/上船事件以宽胶囊按金额降序置顶展示。胶囊集合为看板级单一共享，聚合全部栏的 SC/上船事件，由勾选弹幕的栏统一渲染。

### 胶囊展示

- 用户信息：仅头像（Sender variant="avatar"），不显示昵称、粉丝团牌子、船型标签等非必要元素。
- SC 胶囊：头像+昵称 + 「醒目留言」四字 + 金额（`formatPrice`）；底色用 `scColors.backgroundStart→End` 渐变、文字色用 `scColors.fontColor`；`scColors` 缺失时回退中性底色。
- 上船胶囊：头像+昵称；船型强调色用 `guardLevelTone(level)`（舰长蓝/提督紫/总督红）。
- 金额降序排列；金额相同则新事件优先（arrivedAt 降序）。

### 悬停时长与倒计时

- SC 胶囊悬停时长：取事件 `time` 字段（秒，仅 super_chat）；缺失/非法/非正时回退默认 60s。
- 上船胶囊悬停时长：按船型等级——舰长 60s、提督 5min、总督 1h。
- 胶囊展示时间口径：从事件发生时间（`occurredAt`）起算，已流逝部分扣除——即剩余悬停时长 = 总时长 - (当前时间 - 事件发生时间)。
- 胶囊倒计时到期自动消失；无胶囊时不占位（整个悬停栏隐藏）。

### 点击定位与闪光

- 点击胶囊，信息流按 `eventId` 滚动定位到对应 SC/上船记录并播放一次性闪光（约 1s）。
- 目标不在当前可视/已加载列表（虚拟化回收或分页未加载）时，列表先滚动定位到目标使其可见再闪光——复用 `onLoadMore` 触底加载逐步逼近，到底无更多即停止，不无限循环、不盲目放弃。
- 闪光仅作用于虚拟行内层（不改行高），尊重 `prefers-reduced-motion`（降级为轻微高亮、无位移动画）。

### SC time 字段

- 契约新增可选字段 `time`（整数，秒）：仅 `super_chat` 类型携带。
- 上游来源：`SUPER_CHAT_MESSAGE` payload 标准字段 `data.time`（如 60/120/180/300/3600 档）。
- 服务端 `normalizeSuperChat` 透传 `data.time`，缺失时不携带该字段。
- 前端 `hoverDuration` 对缺失/非法/非正 `time` 回退默认 60s。

### 作用范围

- 仅勾选弹幕（danmaku）的栏显示悬停胶囊栏。
- 胶囊集合为看板级单一共享——聚合全部栏的 SC/上船事件，由勾选弹幕的栏统一渲染，不重复。
- 历史检索（`/api/live-events`）返回的 SC/上船事件同样入胶囊；实时 SSE 到达的事件也入胶囊。
- 混排栏（如「礼物+上船」）加载历史时按栏合并多 type 一次请求，避免逐类多次请求。
- 混排栏分页口径：合并 total 为各类型 total 之和，hasMore 用「合并已加载条数 < 合并 total」判定；合并 total 独立存储，不污染单类型的 totalsBySection。
