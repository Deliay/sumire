# 直播计划管理与周表图生成 Spec

后台 `/backdoor/schedule` 提供直播计划（周表）的维护能力，与公开日历页共用同一日历组件和数据合并规则（见 [calendar.md](calendar.md)）。

## 权限

- 任何登录角色可查看日历与计划详情；member 为只读。
- 新建、编辑、删除计划需 admin 及以上。

## 计划管理

- 点击日历某天弹出日详情浮层；admin+ 可在浮层中新建、编辑、删除计划。
- 计划字段：日期（YYYY-MM-DD，须为真实日期）、开始时间（HH:mm）、标题（trim 后 1–50 字符）。
- 同一天同一开始时间同一标题视为重复，创建/编辑时被拒绝。
- 删除有进行中状态与二次确认；编辑改期后 toast 提示「已移至 M 月 D 日」。
- 表单未填全时提交按钮禁用。
- 日期与时间输入框显式声明 `autoComplete="off"`，关闭浏览器自动填充联想。

## 日历布局

- 月视图周表头与 42 格拆为两个并列网格，格子网格 `grid-rows-6` 六行 `1fr` 等高。
- `DayCell` 保持 `min-h-16` 兜底，公开页流式布局时格子行高与现态一致。
- 后台页面根容器 `h-full min-h-0`，日历/骨架容器 `flex-1 min-h-0` 顶满视口剩余空间。
- 极小视口兜底 `min-h-[480px]`，允许页面滚动不挤压格子。

## 周表图生成

- 后台 schedule 页提供「生成周表图」入口（所有登录角色可用，含 member）。
- 打开弹层时一次性拉取全量计划；ISO-8601 周切换器切换周，切换不重发请求。
- 同一天多场按开始时间升序以「 / 」拼接为单行；文字自动缩放到下限后截断加「…」。
- 预览渲染在官方周表底图上（Noto Serif SC 字体），输出 PNG，移动端长按 / 桌面右键保存。
- 渲染使用 2× 离屏超采样 + `imageSmoothingQuality: "high"` 缩回 1665×1080，文字边缘平滑。

### 周表图片自定义

- 全局设置：对齐（左/中/右）、字号（16-60px，默认 40）、颜色（默认应援色 #b4a6bf）。
- 按天设置：七天折叠面板，每项可编辑内容模板、覆盖对齐/字号/颜色（留空沿用全局）。
- 内容模板支持 `{schedules}` 变量，替换为当天计划文本（HH:mm 标题 / HH:mm 标题）。
- 方案按周保存到 localStorage，默认方案 + 按周方案；无周方案时回退默认方案。
- 任一编辑自动新建本周方案（以当前有效方案为基底），编辑默认方案模式独立切换。
- 重新打开弹层时按当前周加载已保存方案，切换周时重置为对应周方案。

## 骨架动画

- 全站骨架 `animate-pulse` 使用 `@theme` 覆盖的 `--animate-pulse` token，周期 3.2s（原 2s），一处改动全站生效。
- `prefers-reduced-motion` 兜底不变，骨架静态呈现。

## 移动端

<640px 时日历自动切换为周视图（单周 7 天 + 周切换 + 回到今天），管理交互与桌面一致。
