# 公开站页面 Spec

堇色书屋公开站是纯静态站点，包含首页、档案页、素材页三个内容页与全局导航。日历页见 [calendar.md](calendar.md)。

## 全局

- 站点定位：枝堇Sumire（VirtuaReal 二十八期）非官方粉丝站，应援色 `#b4a6bf`；素材版权归主播及所属社团所有，内容以官方公开信息为准。
- 页面骨架：固定顶部 NavBar（雾面玻璃，全屏宽）+ 内容区 + Footer（单行：免责声明 + 三个外链）。**Footer 形态按页面区分**：首页为封面页，在页内底部渲染**通栏贴底毛玻璃条**（`Footer floating`，免责声明全端展示，该页不再经全局布局的流式页脚）；非首页（`/about` `/assets` `/calendar`，位于路由组 `(site)/(content)/`）经 `(content)/layout.tsx` 渲染流式单行页脚——保证首页**单 footer** 且不可滚动。
- 视觉基调：深色底、纸页承载长文、藤蔓分割、flower `#8b5fd6` 点睛（单屏 ≤5%）；动效缓慢呼吸，尊重 `prefers-reduced-motion`。
- 断点：`<640px` / `640–1024px` / `>1024px`。
- **API 配置降级**：未配置 API 时（`NEXT_PUBLIC_API_BASE_URL` 为空），导航不出现「日历」入口、首页不渲染「直播状态 / 今日日程」组件、`/calendar` 与 `/backdoor` 呈现站点 404，且不发任何 `/api/*` 请求。该口径由 `API_CONFIGURED` 统一控制。
- 未上线功能不出现在导航与任何入口（如工具集注册表为空即无入口）。

## 首页 `/`

首页为**一屏封面页**：`100svh` 占满整屏、不可滚动、内容不溢出，任何视口下不产生纵向滚动条。

- 立绘（`standing-01`）：移动端从顶部 10% 起占 90% 高、全宽并向右偏移 25% 宽裁剪展示（`ml-[25%]`）；桌面端右 10% 起占 90% 高、右半宽且不偏移。作为氛围元素（`pointer-events-none`），不遮挡交互区域。
- 文案块（VirtuaReal · 二十八期 / 枝堇 / Sumire / bio）置于**左下角**，留 padding（桌面 > 移动端），错峰入场动画。不再渲染应援色复制按钮。
- 直播状态组件：展示「直播中 / 未开播」状态（降级为中性状态），点击跳转直播间（新窗口）；仅在 API 配置时渲染，固定尺寸骨架防布局跳动。
- 今日日程组件：展示当天直播计划（`HH:mm 主题`），无计划展示「今日暂无安排」，失败静默为空态；仅在 API 配置时渲染。
- 底部：**通栏贴底毛玻璃条** Footer（免责声明全端展示 + B 站空间 / 直播间 / 萌娘百科三外链）。
- 已移除：三张入口卡、信息速览条（生日/种族/所属/粉丝勋章 + 了解更多）、本周日程大卡。

## 档案页 `/about`

纯静态内容页，区块依次为：

- 页头引文；
- 信息卡（蕾丝边框 + 立绘 + 档案定义表）；
- 设定故事（出道故事/介绍按段落排版，含「VirtuaReal 预告专栏（节选）」引用块）；
- 喜好标签组（喜欢 / 不喜欢 / 游戏 / 常读·常看（书籍动漫类型）/ 常听（音乐类型）/ 偏好类型（游戏类型））；
- 历程时间线（藤蔓轴，桌面端左右交错、移动端单侧）；
- 逸闻卡片；
- 官方外链按钮。

## 素材页 `/assets`

- 常驻版权提示纸卡（非官方声明）。
- 画廊：分类筛选（全部 / 立绘 / 插画 / 宣传图）、响应式网格（1/2/3 列），立绘完整 contain 展示、其余 cover 裁切，4:5 占位防布局跳动。
- Lightbox：Esc 或遮罩关闭、锁定背景滚动、焦点初置关闭键、提供原图下载链接。
