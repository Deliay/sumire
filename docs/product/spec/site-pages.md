# 公开站页面 Spec

堇色书屋公开站是纯静态站点，包含首页、档案页、素材页三个内容页与全局导航。日历页见 [calendar.md](calendar.md)。

## 全局

- 站点定位：枝堇Sumire（VirtuaReal 二十八期）非官方粉丝站，应援色 `#b4a6bf`；素材版权归主播及所属社团所有，内容以官方公开信息为准。
- 页面骨架：固定顶部 NavBar（雾面玻璃）+ 内容区 + Footer（蕾丝边、非官方声明、外链、应援色条）。
- 视觉基调：深色底、纸页承载长文、藤蔓分割、flower `#8b5fd6` 点睛（单屏 ≤5%）；动效缓慢呼吸，尊重 `prefers-reduced-motion`。
- 断点：`<640px` / `640–1024px` / `>1024px`。
- **API 配置降级**：未配置 API 时（`NEXT_PUBLIC_API_BASE_URL` 为空），导航不出现「日历」入口、首页不渲染「本周日程」区块、`/calendar` 与 `/backdoor` 呈现站点 404，且不发任何 `/api/*` 请求。该口径由 `API_CONFIGURED` 统一控制。
- 未上线功能不出现在导航与任何入口（如工具集注册表为空即无入口）。

## 首页 `/`

- Hero：立绘展示（移动端降透明度衬底）、错峰入场动画、应援色卡（点击复制色值）。
- 入口卡三张：档案页、素材页、B 站直播间外链（带 badge）。
- 「本周日程」区块：展示本周一~周日（本地时区）的直播计划，每天一行 `HH:mm 主题`，无计划显示「未排期」，加载中显示骨架条，底部链接到 `/calendar`。仅展示计划，不合并历史直播；仅在 API 配置时渲染。计划请求失败显示「日程暂时翻不开了」。
- 「速览」纸页卡片：生日、种族、所属、粉丝勋章四项事实。

## 档案页 `/about`

纯静态内容页，区块依次为：

- 页头引文；
- 信息卡（蕾丝边框 + 立绘 + 档案定义表）；
- 设定故事（出道故事/介绍按段落排版，含「VirtuaReal 预告专栏（节选）」引用块）；
- 喜好标签三组（喜欢 / 不喜欢 / 游戏）；
- 历程时间线（藤蔓轴，桌面端左右交错、移动端单侧）；
- 逸闻卡片；
- 官方外链按钮。

## 素材页 `/assets`

- 常驻版权提示纸卡（非官方声明）。
- 画廊：分类筛选（全部 / 立绘 / 插画 / 宣传图）、响应式网格（1/2/3 列），立绘完整 contain 展示、其余 cover 裁切，4:5 占位防布局跳动。
- Lightbox：Esc 或遮罩关闭、锁定背景滚动、焦点初置关闭键、提供原图下载链接。
